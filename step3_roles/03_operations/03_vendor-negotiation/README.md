## 概要
ベンダーとの契約更新に備え、Claude Cowork で現行契約と更新提案を比較し、レッドラインテーブルと1ページの交渉ブリーフを作る手順を述べた記事です。事前準備は、契約書・更新提案・使用状況のエクスポート・比較見積もりを1つのフォルダに集めることです。プロンプトの例に続き、指示の出し方のコツ6点、スキル化、/schedule による自動実行、チームでの共有が紹介されます。記事は画像のない HTML の変換で、末尾にナビや広告の残りは見当たりません。
