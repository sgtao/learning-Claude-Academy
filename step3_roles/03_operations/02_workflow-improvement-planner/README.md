## 概要
Claude Academy のユースケース記事で、非営利団体の担当者がワークフロー改善の機会を整理する手順を紹介している。まずClaudeに、現状・課題・インプットとアウトプット・成功の状態・制約を問う記入式のアーティファクト（計画テンプレート）を作らせる。次に自分の業務を記入し、完成した内容をClaudeに渡して、有用な機能、ステップごとの進め方、サンプルプロンプトを提案してもらう。無料ツールだけなどの制約に合わせた簡素化の依頼例もある。後半には、具体的に書く、実物を添える、課題を正直に書くなどのコツが並ぶ。本文に見出しはなく、分割なし。画像の中身は読めていない。

## 生成AIの総括
### 良い質問票を書くほど、良い改善案が返ってくる
- 横断分析：
  - 順序：まずClaudeにテンプレートを作らせ、次に人間が現実を記入し、最後にそれをClaudeに返す。AIに考えさせる前に、自分の状況を言葉にする段階が入る。
  - 具体性：期限、ページ数、時間、データの数、件数まで書くことで、Claudeが実際の規模に合う設計を作れる。本文のコツは、ほぼすべてこの点に通じる。
  - 現実への調整：無料ツールだけ、専門知識なし、AI経験が浅いという制約を伝えて、提案を簡素化する。提案は一度で完成せず、会話で整える。
  - 視野の広さ：速度だけでなく、品質、特定の人への依存、規模、ストレスにも目を向け、実物とMCP接続で、Claudeの手元の情報を増やす。
- 一言まとめ：テンプレートは答えを出す道具ではなく、自分の現状をClaudeに正確に伝えるための道具である。
