## 材料から成果物まで、==6 つのプロンプト==
lead: 各プロンプトは下書きとして開かれ、送信前に編集できる
```steps
style: cards
items:
  - { title: 業務プロセスを文書化, desc: タスクの進め方の概要から、標準作業手順書を作る }
  - { title: アクションアイテムを作成, desc: 会議メモや文字起こしから、アクションアイテムとフォローアップメールを作る }
  - { title: ベンダーの見積もりを比較, desc: 複数の見積もりを分析し、推奨事項と確認事項のレポートにする }
  - { title: ステータスレポートを作成, desc: ファイル、メモ、接続済みのプロジェクトやツールから、週次レポートを作る }
  - { title: プロジェクトトラッカーを作成, desc: 手持ちのファイルやドキュメントを、スプレッドシートのトラッカーにまとめる }
  - { title: デイリーブリーフを作成, desc: メール、カレンダー、チャット、メモから、朝のブリーフィングを作る }
```
note: どれも「手元の材料から作る」形なので、まず自分の仕事に近い 1 つを選びます。説明は元ページの 1 行説明をもとに短くしたものです。プロンプトの文面そのものは元ページの本文にありません。

## 試してから、==手順を確かめる==
lead: 本文にあるのは一覧だけ。進め方は筆者の提案（補足）
- **1. 選ぶ**：6 つのプロンプトから、自分の仕事に近い 1 つを選ぶ（補足：進め方の提案）
- **2. 編集して試す**：下書きとして開き、送信前に自分の仕事に合わせて直す
- **3. 事例で確かめる**：近い題名の使用事例を開いて、ステップを確かめる（補足：進め方の提案）
- **まだ分からないこと**：各使用事例の中身、プロンプトの文面、Medidata の説明は本文にない
- **出典**：[Claude Academy オペレーションの役割ページ](https://claude.ai/learning/roles/operations)（取得 2026-11-24）
