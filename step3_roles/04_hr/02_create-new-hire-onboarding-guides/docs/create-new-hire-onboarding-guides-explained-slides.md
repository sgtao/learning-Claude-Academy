# 新入社員の初週ガイドを<br>Claudeで作る
subtitle: 共通の情報と、その人だけの情報を組み合わせる
badges: [人事, オンボーディング, 初めて読む人向け]
note: Claude Academy の使用例ページを、解説メモに基づいて整理したスライドです。非エンジニアの初学者が、自分の仕事でClaudeを使いこなすための自己学習用です。

badge: 概要
## 何ができる資料か
lead: 毎回ゼロから組み立てていた初週の案内を、1通にまとめて作らせる
- **目的**：標準的な会社情報と、新入社員ごとの詳細情報を組み合わせ、歓迎感のある実用的なガイドを作る
- **渡す情報**：名前・役職・入社日・チーム・マネージャーの5点と、標準的な会社情報の場所
- **探させる場所**：カレンダー、Slackチャンネル、アップロードした文書
- **広げ方**：複数人分、画像やリンクの埋め込み、用途別の変換、テンプレート保存
point: ==共通部分は使い回し、個別部分だけ差し替える==のが基本の考え方
note: 【補足】旅行のしおりに例えると、集合場所や持ち物は共通、出発時刻や同じ班の人は個別です。

## 依頼は、==5つの順番==で組み立てる
lead: 情報を渡す → 内容を指定する → 探す場所を指定する → 見た目を伝える → 直す
```steps
style: cards
items:
  - icon: "1"
    title: 新入社員の情報を伝える
    desc: 名前・役職・入社日・チーム・マネージャー
  - icon: "2"
    title: 会社情報を指し示す
    desc: 標準的な情報の場所を教える
  - icon: "3"
    title: 含める内容を列挙する
    desc: 6項目を挙げて、初週ガイドを依頼
  - icon: "4"
    title: 探す場所と見た目を指定
    desc: カレンダー・Slack・文書と、デザインの方針
  - icon: "5"
    title: 具体的に直す
    desc: 思い通りでなければ具体的に指示
```
point: 最初の依頼で、==情報・内容・検索先・見た目==まで伝えるのがコツ
note: 本文の依頼文の順番を、5つの手順に整理したものです。5段階への分け方は解説メモ側の整理で、本文が番号を振っているわけではありません。

## ガイドに含める、==6項目==
lead: 本文の依頼文にある項目と、結果の例で作られた中身
| 項目 | 結果の例で作られたもの |
|---|---|
| ウェルカムメッセージ | 役職とチームに合わせたパーソナルなメッセージ |
| 具体的なスケジュール | 具体的なミーティングやオリエンテーションを含む、日ごとの内訳 |
| オフィスのロジスティクス | Lot Cでの駐車、バッジ受け取り、近くのランチスポット |
| チーム紹介 | 名前、役職、各メンバーの担当業務 |
| ツールとアクセス権 | Figma、Miro、Jira、Slackチャンネルと、使えるようになる時期 |
| 初週によくある質問 | 服装、給料日、誰に助けを求めるか |
point: 結果の例は、==情報豊富でも圧倒されない==バランスを保っている
note: 結果の例の末尾には、主要な連絡先（ITの問題はJake、経費に関する質問は経理チーム）も整理されています。

## 探させる場所と、見た目の指示
lead: 散らばった情報を集めるのも、整えるのも、依頼の中で指定できる
- **カレンダー**：オンボーディングイベントを検索。Google Calendar連携を有効にすると、スケジュールに再構成できる
- **Slackチャンネル**：チームのチャンネル（例は#design-systems）を検索
- **アップロード文書**：会社のハンドブック、オフィスのロジスティクス文書、役職固有のオンボーディング情報
- **見た目**：情報密度が高く美しく整理し、洗練されたタイポグラフィとレイアウトで、一般的な人事フォーマットを避ける
point: ==検索先を先に指定する==と、必要な情報が1か所にまとまる
note: 【補足】自分の職場に置き換えるなら、入社前研修の予定表、所属チームのチャットの場、就業規則や社内ガイドの文書などが候補です。

## ガイドを広げる、==5つの方法==
lead: 最初の1通ができたら、人数・形式・再利用へ広げる
- **個別版**：1つのテンプレートから、4人分を役職別に作る
- **埋め込み**：画像・図・ハイパーリンクを入れる
- **用途別の変換**：印刷用PDF、メール用の箇条書き、プレゼン用スライド
- **デザインの反復**：具体的に指示して、素早く調整する
- **テンプレート保存**：新入社員ごとに、詳細情報だけを入力する
point: 共通は1つのテンプレート、==個別は人ごとに差し替え==
note: 個別版の例は、Alex（エンジニアリング）、Maria（セールス）、Jordan（マーケティング）、Sam（カスタマーサクセス）の4人です。

## つまずきやすい点と、本文にないこと
lead: 解説メモが【補足】【推測】と印を付けた箇所を含みます
- **情報が少ないと**：一般的な人事フォーマットに近い出来になりやすい【推測】。本文はデザインの好みの説明と、ブランドガイドラインの提供を勧めている
- **思い通りでないとき**：具体的な指示で直す。本文は直し方の例を挙げている
- **本文にないこと**：連携が使えるプランや権限、設定画面の操作手順、年（日付は11月4日（月）のみ）
- **生成後の確認**：日時や連絡先は、送る前に人が確かめる【補足】
point: 本文は使用例の紹介。==設定の手順やプランは書かれていない==
note: 本文の画像（結果の例）は、中身を読めていません。

## 学びを、自分の仕事へ持ち帰る
lead: 初週ガイドに限らず、手順書やお知らせ文書にも使える型
- **共通部分は雛形にする**：個人別の部分だけを入れ替える
- **検索先を先に指定する**：カレンダー、チャンネル、文書
- **見た目の好みを言葉で伝える**：ミニマル、大胆、洗練されたコーポレート調など
- **直しは具体的に頼む**：何が悪いか、どうしたいかをセットで
- **最初は1人分から**：うまくいったら複数人・別形式・テンプレートへ【補足】
point: 次の新入社員が、==圧倒されず自信を持って出社できる==ガイドを目指す
note: 【補足】最初は、自分1人分の小さな文書で練習すると取り組みやすくなります。
