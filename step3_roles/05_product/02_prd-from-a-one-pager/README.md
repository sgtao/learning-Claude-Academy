## 概要
本文は、Claude Cowork と一緒に PRD の下書きを作る手順を示す記事である。組織の PRD テンプレート、お手本の PRD、リサーチノートを 1 つのフォルダに集めて Cowork を向け、先にインタビューを頼み、その答えをもとにテンプレートでドラフトを作らせる。依頼文では、目標と非目標の明示、お手本と同じ深さ、未解決の質問へのデザインレビュー用フラグを求める。最後に、確認されていない推測がレビューで見つかるため、送る前に自分で確かめるよう勧める。注意：本文は直接変換で、図は含まれない。題名は取得できず（無題）で、接続ボタンのリンク先は読んでいない。

## 生成AIの総括
### 材料を渡し、聞き取りを任せ、最後は自分で確かめる
- 横断分析：
  - 入力が品質を決める視点：テンプレート、お手本、リサーチノート、インタビューの答えという入力の質が、ドラフトの質をほぼ決める。
  - 順序の視点：材料を置く、聞き取らせる、下書きを作らせる、確かめる、の順で、後ろの工程ほど前の入力に支えられる。
  - レビューを見据える視点：目標と非目標、担当付きの未解決の質問を最初から求めることで、レビューで揉める点を先に見える形にしている。
  - 責任の視点：Cowork は推測でギャップを埋めるため、確認されていない推測を見つけて直すのは、最後に送る人の仕事である。
- 一言まとめ：良い材料と正直なインタビューで下書きを作らせ、確認されていない推測を送る前に自分で消す。
