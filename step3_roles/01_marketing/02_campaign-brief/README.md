## 概要
Claude の Marketing プラグイン、コネクタ、作業フォルダを使い、戦略メモを整形されたキャンペーン概要書に変換する手順のページです。概要書をもとに、キックオフ用の短いプレゼンテーションまで同じ処理で作らせます。セクションの明示、両成果物の同時依頼、ブランドガイドラインの参照、例の追加、複数案の依頼といった工夫を挙げ、最後に作業内容を /campaign-brief という Skill に保存し、平日午前9時のスケジュール済みタスクで自動実行する流れを説明します。本文に見出しは無く、1 つの流れで書かれています。「追加」「接続」などのボタン由来のリンク行が残っています。

## 生成AIの総括
### 一度整えた型を、繰り返し使える仕組みに変える

- 横断分析：
  - 材料を先に揃える：戦略メモ、テンプレート、ブランドガイドラインを 1 つのフォルダに置くと、依頼のたびに説明し直さずに済む。
  - 型を言葉にする：6 項目を列挙し、概要書とプレゼンテーションを一度に頼むことで、構成と内容をそろえる。
  - 型を保存する：作業内容を /campaign-brief という Skill にすると、自分の基準が以降も効く。
  - 回す仕組みを足す：スケジュール済みタスクと共有で、個人の作業からチームの標準へ広げる。
- 一言まとめ：材料と型を決めて Skill にし、平日の朝に自動で回すことで、概要書と説明資料を毎回同じ形で用意できる。
