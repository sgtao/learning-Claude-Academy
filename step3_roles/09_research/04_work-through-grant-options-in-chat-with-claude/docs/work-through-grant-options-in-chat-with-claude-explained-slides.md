# 助成金の選択肢を、==一枚のチャート==で見渡す
subtitle: チャットで Claude に頼み、トレードオフを一度に見て、少数に絞る
badges: [Claude Academy, 技術・ハウツー, はじめて読む人向け]
note: 元ページは Claude Academy の使い方例（助成金の選択肢をチャットで検討する）。このデッキは、その解説メモ（README・解説メモ・FAQ）だけを情報源にしている。Web 検索はしていない。

## なぜ、並べ替えでは足りないのか
lead: 意思決定には、一つの見方だけでは示せない次元がいくつもある
- **並べ替えの限界**：どの並べ替え順序も一つの側面を浮き立たせ、残りを隠してしまう
- **例の状況**：来年の助成金申請で、資金提供者が多い。どの少数に絞って申請書を書くかを決める研究者
- **Claude が用意するもの**：リスク・リワードの散布図／チャートとテーブルを一緒に絞り込むフィルター／ランク付けした候補リストにするボタン
point: 位置・サイズ・色で、すべてのトレードオフを==一度に==見る
note: 記事の言葉では、チャートが回答の一部として表示され、すべてのトレードオフが一度に見えるようになる。

## 進め方は、==4ステップ==
lead: 準備 → 依頼 → 読む → 絞る
```steps
style: cards
items:
  - icon: "📎"
    title: 準備
    desc: 金額・おおよその成功率・期限のシートを添付。なければ状況を説明する
  - icon: "💬"
    title: 依頼
    desc: トレードオフを見える形にしてほしいこと、期限が近いものにフラグを立てることを頼む
  - icon: "👀"
    title: 読む
    desc: 位置・色・サイズと、上部の期待値カードを読む
  - icon: "🎚️"
    title: 絞る
    desc: 期限・成功率・助成額のフィルターで、チャートとテーブルを一緒に絞る
```
point: 厳密に必須のものはない。実際のパイプラインに基づくなら、シートを添付する
note: 最初の依頼は、大きな資金を狙う一発勝負と、小さな助成額でも確実性の高いものを、実際に見える形で示してほしい、という内容。シートが無いときは、Claude が主要なプログラムについて知っている情報から補完する。

## チャートの読み方
lead: 記事の例では、軸は助成額と推定成功率
| 見るもの | 意味 |
|---|---|
| 位置 | トレードオフ。一発勝負は左上、確実性の高い案件は右下 |
| 色 | 時間の切迫度。赤は30日以内、アンバーは90日以内、青はそれ以降 |
| サイズ | 申請にかかる手間（労力） |
| 期待値カード | 現実性を考慮した唯一の数値。単純合計との差が、くじの度合い |
point: 両隅の間の距離が、あなたの戦略の位置を示す
note: 記事の画像の説明にある例示の値は、18件のプログラム、700万ドルの総パイプライン、92.7万ドルの期待値、4件の緊急期限。あなたの候補の値ではない。期待値の計算方法は本文には書かれていない。

## 続けて頼める、==3つ==
lead: チャートは作って終わりではなく、対話で育てる
```steps
style: circled
items:
  - icon: "🔍"
    title: 点を開く
    desc: 点をクリックすると、チャートはそのまま、下にプロフィールが開く
  - icon: "📅"
    title: 日程にする
    desc: 90日以内の助成金を、各期限から逆算した開始日つきのスケジュールにする
  - icon: "🔄"
    title: 更新する
    desc: 提出済みを伝えると、「進行中」に移して再描画し、残りを再ランク付けする
```
point: 記事の例（NSF CAREER、R03）は、自分の候補名に置き換える【補足】
note: 点を開く例は NSF CAREER の期限・ページ数の上限・競争力のある要素。更新の例は、昨日 R03 を提出した、という伝え方。置き換えの助言は解説メモで足した補足で、記事の文ではない。

## 注意点と、使い続け方
lead: チャートは意思決定の形を示すもの
- **補完した数値**：シートなしでは、主要な連邦プログラムは成功率がおおむね正確。公開していない財団は確実性が低い
- **決める前に確認**：申請書を書く前に、個々の点はプログラムのページで確認する
- **Artifact で保存**：シーズンの途中で戻り、一件提出したら Claude に伝えて再描画する
- **ほかの意思決定にも**：人員配置、ロードマップの優先順位など、一つの列で並べ替えられないもの
point: 形をつかむのはチャート。決める前の裏取りは、自分で行う
note: チャートの上にマウスを置くと、画像をコピーするか Artifact として保存するかを選べる。

## まとめ
1. **見せ方**：位置・色・サイズで、並べ替えでは隠れる次元を一度に見る
2. **進め方**：準備 → 依頼 → 読む → 絞る。そのあと点の詳細・日程・更新を頼む
3. **使い方**：数値は確認し、Artifact に残して、状況が変わるたびに再描画する
> 次に試す1つ（補足）：何度も並べ替え直している自分の意思決定で、軸にしたい2つの要素と、色・サイズに回す要素を言葉にして、Claude に頼んでみる
note: 最後の問いかけは、元の記事の結びの趣旨（何度も並べ替え直している意思決定で試す）に沿って足した。
