## 6つのプロンプトは「==資料を渡して成果物を受け取る==」形
lead: 入力は手元の下書き・論文・データ・フォルダ。自分の作業に近いものは入力から選ぶと探しやすい
```steps
style: cards
items:
  - { icon: "📝", title: レポートの下書きを推敲, desc: 学術論文の修正案を提示してもらえる }
  - { icon: "💰", title: 助成金申請書の下書きを作成, desc: 助成元の審査基準に沿ったアウトラインを作成 }
  - { icon: "📄", title: 研究論文の概要を作成, desc: 要旨または全文から構造化された要約を作成 }
  - { icon: "🗺️", title: 文献マップを作成, desc: 論文やPDFを横断し、テーマ・手法・研究結果のマップを作成 }
  - { icon: "📊", title: データ分析を実行, desc: グラフと、前提を明記した簡潔な結果のまとめ }
  - { icon: "🗒️", title: リサーチメモを作成, desc: フォルダ内の資料を関係者向けにまとめ、すべての主張に出典を明記 }
```
note: 6つは順番ではなく並列の選択肢です。選び方の「入力から選ぶ」は解説メモの整理（筆者の補足）です。

## 似た3つは「渡すもの」と「受け取るもの」で見分ける
lead: 概要・文献マップ・リサーチメモの違い
| | 研究論文の概要 | 文献マップ | リサーチメモ |
|---|---|---|---|
| 渡すもの | 1つの論文（要旨または全文） | あるトピックの論文やPDF（複数） | フォルダ内の論文・レポート・メモ |
| 受け取るもの | 構造化された要約 | テーマ・手法・研究結果を含むマップ | 関係者向けの簡潔なメモ |
| 出典の明記 | 本文に記載なし | 本文に記載なし | すべての主張に明記 |
point: 数字を扱う「データ分析」は==前提を明記==、リサーチメモは==出典を明記==する、と書かれている
note: 出典の明記が「本文に記載なし」とは、説明文に書かれていないという意味で、できないという意味ではありません。

## 初めてなら、==4つの動き==で始める
lead: 解説メモの活用案をもとにした筆者の整理（本文の手順ではない）
```steps
style: cards
items:
  - icon: "🔍"
    title: 選ぶ
    desc: 手元の資料に近いプロンプトを1つだけ選ぶ
  - icon: "✏️"
    title: 書き換える
    desc: 下書きを開き、対象・相手・必要な形式を足してから送る
  - icon: "✅"
    title: 確かめる
    desc: 前提や出典を手がかりに、結果を元の資料と見比べる
  - icon: "📚"
    title: 学ぶ
    desc: 使用事例から、分数の短い1件を選んで読む
```
point: 全部を一度にやらず、==1つずつ==試して、うまくいった書き換えを残す
note: 送信前に何を書き換えるかは本文に書かれていません。下書きの文言は一般的な形なので、誰が読むか・何のためか・どの資料かを足すと自分の仕事に近づく、というのは推測です。
