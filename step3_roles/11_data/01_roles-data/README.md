## 概要
Claude Academy のデータの役割ページを、Chrome で読んだ本文（テキストのみ）です。ページは大きく二つの部分でできています。一つ目は「プロンプトを試す」で、SQL の作成、データパイプラインのデバッグ、A/B テストのレポート、ダッシュボード、週次の指標レポート、データファイルのクレンジングの六つの依頼文が並び、下書きとして開かれて送信前に編集できます。二つ目は「使用事例」で、ユースケース（10分）とチュートリアル（13分）が一つずつ載っています。ボタンのリンク先や画像は読めておらず、各使用事例の中身は本文に書かれていません。

## 生成AIの総括
### 「下書きを直して送る」と「事例で手順を追う」の二本立ての入口
- 横断分析：
  - 構造：ページは「すぐ試せるプロンプトの一覧」と「手順を追える使用事例」の二層でできている。
  - 学び方：プロンプトは自分の状況に合わせて編集してから送る前提で、まる写しではなく調整を促している。
  - 範囲：一覧が扱うのは、問いへの回答、不具合の原因探し、報告、ダッシュボード、指標、データの整理と、データ業務の一通りの場面。
  - 限界：本文は一覧だけで、事例の中身や結果は書かれていないため、学ぶには実際に開いて確かめる必要がある【推測】。
- 一言まとめ：このページは、データ作業の依頼文を自分用に編集して試し、必要なら事例で手順を確かめる入口である。
