## FAQ｜グループ1：データの役割ページの全体像
### 1. このページでは何ができますか
- **質問**：データの役割ページには何が載っていて、何ができますか。
- **回答**：データ作業向けのプロンプトの一覧と、使用事例（ユースケースとチュートリアル）の一覧が載っています。プロンプトは下書きとして開かれ、送信前に編集できます。
- **具体例**：週次の指標をまとめたいときは、「週次の指標レポートを作成する」を選び、下書きを自分の状況に直してから送ります。
- **該当箇所**：本文（見出しなし）「各プロンプトは下書きとして開かれ、送信前に編集できます。」

### 2. プログラミングができなくても使えますか
- **質問**：SQL やデータパイプラインの知識がなくても、役に立ちますか。
- **回答**：本文は対象者の経験を書いていません。【補足】一覧には SQL やデータパイプラインに関わるものがありますが、ダッシュボードや週次の指標レポートのように、報告に近い項目もあります。自分の仕事に近いものから試すのが現実的です。
- **具体例**：【補足】SQL に触れない人は、まず「ダッシュボードを作成」や「週次の指標レポートを作成する」のような報告系の項目を選ぶ、という使い方があります。
- **該当箇所**：本文（見出しなし）「クエリを作成: データに関する重要な問いに答える SQL を作成します。」

### 3. データパイプラインのデバッグでは何をしてくれますか
- **質問**：「データパイプラインをデバッグ」のプロンプトは、何をするものですか。
- **回答**：失敗や遅延が発生しているデータパイプラインについて、考えられる原因を特定するものです。本文は「特定します」と書いており、直すところまでは書いていません。
- **具体例**：【補足】夜間の取り込みが終わらない、といった状況を言葉で伝え、原因の候補を挙げてもらう使い方が考えられます【推測】。
- **該当箇所**：本文（見出しなし）「データパイプラインをデバッグ: 失敗や遅延が発生しているデータパイプラインについて、考えられる原因を特定します。」

### 4. A/B テストのレポートには何が入りますか
- **質問**：「A/B テストのレポートを作成」で作られるサマリーには、何が含まれますか。
- **回答**：結果と推奨事項を含む A/B テストのサマリーです。
- **具体例**：【補足】二つの案内文のどちらが反応がよかったかを、結果と次の一手の形でまとめてもらう場面です。
- **該当箇所**：本文（見出しなし）「A/B テストのレポートを作成: 結果と推奨事項を含む A/B テストのサマリーを作成します。」

### 5. ダッシュボードと週次の指標レポートは何が違いますか
- **質問**：二つのプロンプトの違いは何ですか。
- **回答**：本文からは、ダッシュボードは「実際に使える」ものを作ること、週次の指標レポートは「週次の指標をまとめる」ことが読み取れます。入力は、前者がエクスポートしたデータ、後者がエクスポートしたデータや接続済みのソースです。
- **具体例**：【補足】一度作って見続ける画面がダッシュボード、毎週の報告文が週次の指標レポート、と考えると区別しやすくなります【推測】。
- **該当箇所**：本文（見出しなし）「ダッシュボードを作成: エクスポートしたデータから、実際に使えるダッシュボードを作成します。」と「週次の指標レポートを作成する: エクスポートしたデータや接続済みのソースから、週次の指標をまとめます。」

### 6. データファイルのクレンジングで元のファイルはどうなりますか
- **質問**：クレンジングで、変更はどのように残りますか。
- **回答**：既存のデータファイルをクリーニングし、加えたすべての変更をログに記録します。元のファイルが上書きされるかどうかは、本文には書かれていません。
- **具体例**：【補足】表記ゆれを直したら、どの行をどう直したかの一覧が残るイメージです。実際に試すときは、元のファイルを別に保管してからにすると安心です。
- **該当箇所**：本文（見出しなし）「データファイルのクレンジング: 既存のデータファイルをクリーニングし、加えたすべての変更をログに記録します。」

### 7. 使用事例には何が載っていますか
- **質問**：「使用事例」には、何が載っていて、どれくらいの時間がかかりますか。
- **回答**：実際のワークフローをステップごとに説明するもので、ユースケースが一つ（10分）、チュートリアルが一つ（13分）です。分数が何の所要時間かは、本文に書かれていません【推測】。
- **具体例**：【補足】短いユースケースで流れをつかみ、次にチュートリアルで手を動かす、という順が考えられます。
- **該当箇所**：本文（見出しなし）「実際のワークフローをステップごとに説明します。」「10分 ユースケース Answer the ad-hoc data question」「13分 チュートリアル Using Databricks for Data Analysis」
