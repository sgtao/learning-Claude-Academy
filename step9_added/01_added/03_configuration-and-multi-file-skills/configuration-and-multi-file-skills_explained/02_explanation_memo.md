## 解説
### 1. 要約
このページは、Claude Code で skill を設定する方法と、複数ファイルからなる skill の構造の扱い方を学ぶ 4 分の動画の案内である。本文に書かれているのは、1 文の説明と、動画の訂正の注記だけである。訂正は、動画の 0:40、1:20、3:35 で「allowed-tools」が Claude の使えるツールを制限すると述べている箇所についてのもので、実際には、リストしたツールを事前に承認するだけであり、次のメッセージを送るまで確認なしで使えるという内容である。他のツールは通常の権限設定のもとで使える。skill が有効な間にツールを取り除くには「disallowed-tools」を使う。設定の手順や、ファイルの書き方は本文に無い。

### 2. 例え話
【補足】「allowed-tools」は、作業員に「この道具は確認なしで使ってよい」と前もって渡す許可証に似ている。「禁止の札」（disallowed-tools）とは違い、許可証を渡しても、ほかの道具は今までどおり確認を経て使う。動画の説明（制限する）と訂正（承認する）の違いは、この許可証と禁止の札の違いにあたる。
