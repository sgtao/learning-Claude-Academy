## ==完成した成果物==まで引き受ける
lead: ファイルや接続されたツールにまたがる作業を任せる仕組み
- **引き受ける範囲**：ファイルや接続されたツールにまたがるタスク全体
- **やること**：フォルダや接続済みのサービスから情報を読み取り、複数のステップで作業する
- **結果の置き場**：開くことができる場所に保存する
- **始める場所**：デスクトップアプリか claude.ai にサインイン。ファイルを扱うならデスクトップアプリ
point: Cowork タブが無ければ、新しい会話を始めるだけでよい
note: 出典：原本（見出しなし）の第 1 段落と第 2 段落。解説メモ 02「3. セクション別の解説」の (a)(b)。

## 新しい会話で ==/setup-claude== を入力
lead: Enter を押すと、Claude が会話の中でセットアップを案内する
- **役割を選ぶ**：自分の役割
- **プラグインを入れる**：その役割に合ったもの
- **ツールを接続する**：Slack、Google Workspace、Microsoft 365、役割に関わるシステム
- **何度でも**：新規ユーザーには Set up Cowork バナー。このスキルはいつでも再度利用できる
point: 終えると、空のセッションではなく、作業の出発点が手に入る
note: 出典：原本（見出しなし）の /setup-claude の段落（「Claudeが会話の中でセットアップを案内します」ほか）。
note: 補足の有無：なし。原本はこれを「スキル」と呼んでいる（解説メモ 02 の「キー概念」）。

## プラグインは、==役割ごとのひとまとめ==
lead: スキル・コネクタ・サンプルプロンプトを 1 つにしたもの
- **中身**：ある役割のためのスキル、コネクタ、サンプルプロンプト
- **もっと探す**：すべてのプラグインを閲覧、またはサイドバーの Customize からコネクタを追加
- **使い始め**：/ と入力すると、インストールしたプラグインの開始用プロンプトが表示される
point: 役割別の例は、Cowork のユースケースのページで探せる（本文の案内）

## 作業場所は、==フォルダかプロジェクト==
lead: チャットバーの Work in a folder で、読み書きする場所を指定する
| 観点 | フォルダ | プロジェクト |
|---|---|---|
| 置き場 | コンピューター上（デスクトップアプリの場合） | サイドバーの「プロジェクト」から作成 |
| 働き | 内容を読み取り、新しいファイルをその隣に保存 | セッションをまたいで独自のファイル・指示・記憶を保持 |
| 広さ | 1つの作業に絞る／複数のタスクが共有する広いディレクトリ | 本文には書かれていない |
point: どちらを選ぶべきかは、本文には書かれていない
note: 出典：原本（見出しなし）の Work in a folder の段落と、作業場所の 2 つのリスト。
note: 【推測】1 回きりの作業ならフォルダ、続けて使う作業ならプロジェクト、という使い分けは解説メモ 03 の推測であり、本文には無い。スライドにも書いていない。

## 最初のタスクは、==3つの条件==から選ぶ
lead: 作業フォルダを設定し、必要な結果を説明する
- **条件 1**：複数のツールにまたがる
- **条件 2**：複数のステップが必要
- **条件 3**：コンピューター上で実際の作業が必要
- **依頼の例 1**：このフォルダ内のリサーチを 1 ページのブリーフにまとめてください
- **依頼の例 2**：先週の Slack と Linear の活動からステータスサマリーを作成してください
- **依頼の例 3**：これらの PDF の数値で予測モデルを更新してください
point: 作業フォルダを設定し、必要な結果を説明する
note: 出典：原本（見出しなし）の最後から 2 番目のブロック（新しいタスクを開始する段落と 3 つの例文）。例文は原本の文を、語尾を整えて載せている。

## この回の==教訓==と、次の 1 件
lead: 先に場所と道具を決めてから、最初の仕事を頼む
1. **先に決める**：役割と道具は /setup-claude、作業場所は Work in a folder
2. **頼み方の型**：材料と欲しい結果を 1 文で言い切る（本文の例文 3 つに共通）
3. **空白は自分で確かめる**：所要時間・プランや権限の条件・アクセス範囲
4. **次の 1 件**：自分の仕事から、フォルダに資料がまとまった作業を 1 つ選ぶ
point: 次の一歩：作業フォルダと「欲しい結果の 1 文」を書き出す
note: 出典：解説メモ 06_summary 由来の総括（README「生成AIの総括」）と、02「5. 理解を深める質問」。
