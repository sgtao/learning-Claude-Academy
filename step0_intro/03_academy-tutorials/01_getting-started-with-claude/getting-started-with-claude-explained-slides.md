## 回答の形式は、==必要なものを頼む==
lead: 形式の種類は増え続けている、と本文は述べている
- **チャット内の回答（既定）**：まずはこれが返ってくる
- **図・チャート**：「これがどう動くか見せて」「このデータをチャートにして」で、言葉と一緒に描かれる
- **成果物**：会話の中で作られ、チャットの横に開く。チームと共有でき、サイドバーのアーティファクトタブで見つけ直せる
- **ファイル**：数式入りのスプレッドシート、送付用のPDF、PowerPoint用のプレゼンなど、形式そのものが必要なとき
point: 実際に必要なものをリクエストする
note: 出典は原本の回答の形式を述べた各段落（チャット内の回答・図やチャート・成果物・ファイル作成）です。

## 成果物は6種類、==プランの条件==は一部だけ
lead: プランの条件は、本文に書かれている範囲だけを載せた
| 種類 | できること | プランの条件 |
|---|---|---|
| Claude Design | 画面・フロー・ビジュアルを、手動で編集できるアートボードにレイアウト | 本文に記載なし |
| Claude Slides | Claude内で発表。PowerPoint・PDFでダウンロード、Google Slidesへエクスポート | 本文に記載なし |
| Claude Docs | チームが読み、コメントし、Claudeと一緒にその場で編集 | 本文に記載なし |
| Claude Dashboards | データのダッシュボード。各チャートに最終更新時刻 | 有料プランでベータ版（要確認: どの有料プランか） |
| Claude Motion | アニメーションの説明・チャート・ウォークスルー。MP4でダウンロード | TeamとEnterpriseでベータ版 |
| インタラクティブなアーティファクト | プランナー・計算機・小さなツール | 本文に記載なし |
point: Enterpriseでは、有効にする種類を組織のOwnerが選ぶ

## ＋メニューの==5つの追加オプション==
lead: タスクに必要なときに使える（本文の並び順）
| 項目 | 本文の説明 |
|---|---|
| コネクタ | メール・カレンダー・ドライブ・チャット・CRMなど、使用中のアプリでClaudeに読み取りや操作をさせる |
| ウェブ検索 | Free・Pro・Maxは既定でオン。Team・Enterpriseは既定でオフ（管理者がオンにできる）。回答をドキュメントのみから得たいときはオフ |
| リサーチ | 多数の検索を実行し、出典付きの1つのブリーフを返す。数分かかるので大きな質問向け |
| スキル | 毎回同じ方法で行う作業の保存済みの指示。デスクトップアプリでは、実行の様子を記録して保存もできる |
| フォルダを追加 | ファイルを1つずつ上げる代わりに、コンピュータ上のフォルダ全体を渡して読み取りや保存をさせる（デスクトップアプリ） |
point: 資料だけを根拠にしたいときは、ウェブ検索をオフにする
note: 出典は原本の「＋メニュー」の箇条書き5つです。コネクタの「一度オンにすれば、すべての会話で…」という説明も同じ箇所にあります。
note: ウェブ検索そのものが何をするかの説明は、本文にはありません（既定のオン・オフと、オフにする場面だけが書かれています）。

## 毎回の説明を減らす==3つの引き継ぎ==
lead: 一度説明したら、もう一度説明しなくてよいようにする機能
- **プロジェクト**：1つの継続的な作業の場所。ファイルと数行の指示（ブランドの声・フォーマット・忘れてはいけないこと）を置くと、中の会話は最初から前提を知った状態で始まる
- **Claudeへの指示**：設定プロフィール内の短いメモ。自分が誰か、何を前提とするか、どう話しかけるか。一度設定すればどこでも適用される
- **メモリ**：会話をまたいでClaudeが記憶する内容。設定でオンにすると、使ううちに埋まっていく。いつでも読んだり編集したりできる
point: 同じ説明やアップロードを繰り返していたら、プロジェクトを作る
note: 出典は原本の引き継ぎ機能を述べた段落と、その下の3つの箇条書きです。
note: 3つの使い分けの詳しい基準は本文に書かれていません（解説メモ 02「5. 理解を深める質問」の回答より）。

## 使える場所と、==困ったとき==
lead: 出発点はチャット。ほとんどの人がチャットから始める
- **広がる先**：デスクトップアプリ／Claude Code（エンジニア・開発者向け）／Claude Design／Claude Tag（Slack）
- **アプリの中で**：Excel・Word・PowerPoint・Outlook・Chrome・モバイル
- **困ったとき ①**：機能の仕組みをClaudeに尋ねる
- **困ったとき ②**：出力を良くするプロンプトを、質問してから書いてもらう
- **困ったとき ③**：見覚えのない画面はスクリーンショットを貼って尋ねる
point: 分からないことは、Claude自身に聞いてよい
note: 出典は原本の使える場所の箇条書きと、トラブルシューティングの箇条書き3つです。
note: Claude Code はエンジニア・開発者向けと本文にあります。非エンジニアの最初の一歩はチャットで足りる、というのは解説メモ 02「テーマ：Claudeを使い始める最初の日」の【補足】であり、本文の記述ではありません。
