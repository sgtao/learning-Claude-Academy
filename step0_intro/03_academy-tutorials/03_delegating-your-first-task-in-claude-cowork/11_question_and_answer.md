## FAQ｜グループ1：最初のタスクを任せる流れ
### 1. Cowork では何を任せられますか
- **質問**：Cowork では、どんな場所にある作業を Claude に任せられますか。
- **回答**：コンピュータ上、クラウド上、ブラウザ上の作業を任せられる。コンピュータ上なら Claude が見つけて編集し、クラウド上なら Google Drive・Notion・Slack などのサービス経由で接続し、ブラウザ上なら Claude in Chrome を通じて扱う。
- **具体例**：本文の例は、コンピュータ上の Downloads フォルダの整理。
- **該当箇所**：本文（見出しなし）「それがブラウザ上にあれば、Claude in Chromeを通じてそこにもClaudeがいます」

### 2. どのプランと OS で使えますか
- **質問**：Cowork はどのプラン・どの OS で使えますか。
- **回答**：Pro・Max・Team・Enterprise のユーザー向けで、macOS と Windows の Claude Desktop アプリで一般提供されている。各プランの違いや料金は、本文には書かれていない。
- **具体例**：始めるには、Claude Desktop を開いて Cowork タブをクリックする。
- **該当箇所**：本文（見出しなし）「Claude Coworkは、Pro、Max、Team、Enterpriseユーザー向けに、macOSおよびWindows用のClaude Desktopアプリで一般提供されています」

### 3. 普通のチャットとは何が違いますか
- **質問**：通常の Claude チャットと Cowork は、どこが違いますか。
- **回答**：チャットは Claude と段階的に作業を進める。Cowork はタスクを引き渡し、人が他の作業に集中している間に Claude が残りを処理する。
- **具体例**：ファイル整理で、チャットは方法の説明まで、Cowork は実際の整理まで行う。
- **該当箇所**：本文（見出しなし）「通常のチャットでは、Claudeはファイルの整理方法を説明することしかできませんでした」

### 4. 最初に何を準備しますか
- **質問**：最初のタスクを任せる前に、何を準備しますか。
- **回答**：本文の順序では、まずコンピュータ上のフォルダへのアクセスを与え、次にコネクタでツールを接続し、三つ目に Claude in Chrome を設定済みなら使える。グローバルな指示は設定の下の Cowork タブで任意に設定できる。
- **具体例**：Claude に操作してほしいフォルダを選ぶ。よく使うフォルダはお気に入り登録でき、複数のフォルダも選べる。
- **該当箇所**：本文（見出しなし）「よく使うフォルダをお気に入り登録したり、複数のフォルダを選択して異なるデータソースを接続したりすることもできます」

### 5. Claude が勝手にファイルを変えませんか
- **質問**：Claude はファイルを勝手に変更しますか。
- **回答**：本文では、ファイルシステムに変更を加える前に許可を求めてくる。また、基本ループとして、計画を提案し、行動の前に承認を待つ。
- **具体例**：本文の例では、変更を加える前に計画を見せるよう伝えている。
- **該当箇所**：本文（見出しなし）「Claudeは計画を提案し、行動を起こす前にあなたの承認を待ちます」

### 6. 途中で方針を変えられますか
- **質問**：計画の内容を途中で変えたいときは、どうしますか。
- **回答**：計画を調整したり、方向を変えたり、特定のステップをスキップするよう指示したりできる。
- **具体例**：重複に見えた 4 つのうち 2 つが別バージョンだったので、削除せずレビューフォルダに移し、残りは進めるよう伝えた。
- **該当箇所**：本文（見出しなし）「計画を調整したり、アプローチの方向を変えたり、特定のステップをスキップするようClaudeに指示したりできます」

### 7. 作業中に気を付けることは何ですか
- **質問**：Claude が作業している間、使う側が気を付けることはありますか。
- **回答**：セッションはデバイス上にローカルに保存される。タスクの間、デスクトップアプリを開いたままにする。進捗は右上隅で確認でき、各タスクをクリックして詳細の確認や質問ができる。
- **具体例**：整理中、ファイルは実際に自分のマシン上で移動する。
- **該当箇所**：本文（見出しなし）「Claudeがタスクに取り組んでいる間、デスクトップアプリは開いたままにしておく必要があります」

### 8. 最初の 1 件は何を選べばよいですか
- **質問**：最初に任せる作業は、どう選べばよいですか。
- **回答**：本文は、境界が明確なタスクから始め、Claude が生成したものは必ず確認するよう勧めている。任せるのは作業で、判断ではない。具体的な選び方の基準（件数・時間など）は、本文には書かれていない。
- **具体例**：本文の例は、フォルダ整理（Downloads）。
- **該当箇所**：本文（見出しなし）「あなたが委任しているのは作業であり、判断ではありません」
