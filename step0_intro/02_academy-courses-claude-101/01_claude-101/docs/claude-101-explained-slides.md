## 前提と、有料プランが要る機能
lead: 前提はアカウントだけ。ただし一部の機能は、試すのに有料プランが必要
| 機能・条件 | 必要なプラン | 本文の記述 |
|---|---|---|
| アカウント | Free、Pro、Max、Team、Enterprise のいずれか | 任意のプラン |
| Cowork | Pro、Max、Team、Enterprise | 有料プランが必要 |
| Research 機能 | Pro、Max、Team、Enterprise | 有料プランが必要 |
| Enterprise Search | Team、Enterprise | 有料プランが必要 |
| デザイン・プレゼンテーション・ドキュメント | Team・Enterprise では管理者の設定による | 利用可否は管理者の設定 |
point: 自分のプランで試せる機能を、先に確かめておく
note: 根拠は原本の前提の箇条書き（3 項目）。解説メモ 02 の「3. セクション別の解説」・11 の FAQ 2・4・5。
note: Free のアカウントでは Cowork・Research・Enterprise Search は試せないと読めるが、これは解説メモの推測で、本文に明記はない。
note: 該当する箇所は各レッスンで注記されると本文にあるが、注記の中身は本文には書かれていない。

## 自分の仕事に、どう使う？
lead: 本文は対象を示すだけ。使い方の場面は、解説メモの整理（補足）
- **本文の対象**：職場でClaudeを使い始めるすべての人が対象
- **（補足）いつ**：使い始める前、または使い始めて間もないとき
- **（補足）どうやって**：自分のプランを確かめ、仕事 1 件を題材に最初の会話を試す
- **（補足）目標**：読んだあとに、自分の仕事 1 件で Claude を試せる状態になる
point: 小さく 1 件。最後まで試すことが目標
note: 補足を足した箇所は、「（補足）」を付けた 3 項目。出典は解説メモ 02_explanation_memo.md の「4. ユースケース」と「活用案」の案 1。
