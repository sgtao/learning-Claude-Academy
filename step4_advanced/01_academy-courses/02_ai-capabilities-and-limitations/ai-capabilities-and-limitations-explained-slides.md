badge: はじまり
## なぜ、AI は==時々おかしい==のか
- 難解な報告書を、数秒で見事に要約する
- 存在しない引用文献を、自信満々に作る
- 詳細な指示に従ったのに、単純な指示を無視する
point: その裏の理由を知らないと、次の出力を信頼してよいか分からない
note: 原本の冒頭の段落による。

## AI の得意と不得意を==4 つ==で見る
lead: 能力から限界へ続くスペクトル上に、それぞれの特性がある
```steps
style: cards
items:
  - { icon: "🔮", title: 次トークン予測, desc: 答えがどこから来るか }
  - { icon: "📚", title: 知識, desc: 何を知っていて、なぜ自信満々に間違えるか }
  - { icon: "🧠", title: 作業記憶, desc: 何に注意し、何がこぼれるか }
  - { icon: "🎛️", title: 操縦性, desc: 指示でどこまで制御できるか }
```
point: 各特性を、説明と演習の組で体感する
note: 4 特性の名前と問いは原本の段落による。演習の中身は本文に無い。
---
<!-- slide: points -->
badge: 衝突
## 実際の利用では、特性が==ぶつかる==
- **長い文書**：作業記憶に負荷をかけ、知識の外へ踏み込ませる
- **曖昧な指示**：次トークン予測が最もそれらしい答えを探す場面で、操縦性を試す
note: 原本の最後のセクションの段落による。

## 自分の仕事の==想定外==を一つ書き出す
1. **1 件選ぶ**：最近の想定外の出力
