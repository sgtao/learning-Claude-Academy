スキルとは、特定のタスクでClaudeのパフォーマンスを向上させるために動的に読み込まれる、指示・スクリプト・リソースをまとめたフォルダです。専門知識のパッケージと考えてください。特定のタスクを一貫した方法で完了する方法をClaudeに教えてくれます。

Claudeを使ってExcelスプレッドシート、PowerPointプレゼンテーション、Word文書、PDFを作成したことがあれば、すでにスキルの働きを体験しています。これらのファイル作成機能は、裏側で動作するスキルによって実現されています。しかし、スキルの用途はドキュメント作成にとどまりません。カスタムスキルを使えば、四半期の差異分析手法、ブランドボイスのレビュープロセス、コンプライアンスチェックリストなど、繰り返し行うワークフロー全体を体系化できます。これにより、Claudeは毎回同じ厳密な手順に従って作業を進められます。

スキルには2つのカテゴリがあります。

- **Anthropicスキル**は、Anthropicが作成・管理しているスキルです。Excel、Word、PowerPoint、PDFファイルの高度な作成機能が含まれます。関連するタスクの際にClaudeが自動的に呼び出すため、特別な操作は必要ありません。
- **カスタムスキル**は、ご自身または組織が特定のワークフローやドメイン固有のタスク向けに作成するスキルです。たとえば、プレゼンテーションに自社のブランドガイドラインを適用するスキル、会議メモを特定のフォーマットで構造化するスキル、組織のデータ分析ワークフローを実行するスキルなどを作成できます。

スキルはすべてのプランで利用できます。スキルを使用するには、コード実行とファイル作成を有効にする必要があります。スキルはClaudeの安全なサンドボックス環境で動作するためです。

ウェブまたはデスクトップアプリでスキルを有効にする手順は以下のとおりです。

1. 左下隅の名前をクリックし、**設定 > 機能**に移動します。
2. **コード実行とファイル作成**がオンになっていることを確認します。（TeamおよびEnterpriseプランでは、組織のオーナーが組織設定でこれを制御するため、このトグルは表示されません。手順3に進んでください。）
3. 左サイドバーから**カスタマイズ > スキル**を開きます。
4. スキルをクリックして開き、ページ上部のスイッチを使ってオン・オフを切り替えます。

**Enterpriseプラン**の場合、個々のメンバーがアクセスできるようになる前に、組織のオーナーが組織設定でコード実行とスキルの両方が有効になっていることを確認する必要があります。

**Teamプラン**の場合、この機能は組織レベルでデフォルトで有効になっています。

有効化すると、**カスタマイズ > スキル**に利用可能なスキルの一覧が表示されます。Anthropicの組み込みスキルと、アップロードしたカスタムスキルの両方が含まれます。

スキルの素晴らしい点は、通常は意識する必要がないことです。Claudeがリクエストに基づいて自動的に適切なスキルを選択します。スキルが呼び出されるプロンプトの例をいくつか紹介します。

- “月々の経費を追跡するExcelスプレッドシートを作成して、合計の数式も入れてください”
- “この会議メモをPowerPointプレゼンテーションに変換してください”
- “このデータをまとめたPDFレポートを作成してください”
- “シナリオ分析機能付きの財務モデルをExcelで作成してください”

Claudeがスキルを使用する際は、作業中の思考プロセスの中でスキルが使用されていることが表示されます。出力はダウンロード可能なファイルとして生成され、コンピュータに保存したり、Googleドライブに直接保存したりできます。（Claude SlidesとClaude Docsが有効になっている場合は、プレゼンテーションやドキュメントを依頼すると、代わりにアーティファクトが作成されることがあります。アーティファクトならClaudeと一緒に作業を続け、完成したらエクスポートできます。両者の違いは「アーティファクトで作成する」のレッスンで説明しています。）

**Claudeはスライド、スプレッドシート、契約書の修正などを一緒に作業できます**

このレッスンの動画にはナレーションが含まれていません(画面デモンストレーションとバックグラウンド音声のみ)。

この機能により、Claudeは（隔離された環境内で）**実際のファイル**を扱い、更新版を作成することができます（注：チャットでファイルをアップロードした場合、Claudeは元のファイルをその場で編集するのではなく、新しいバージョンを作成します）。スライド、スプレッドシート、契約書（または任意の.xlsx、.pptx、.docx、.pdfファイル）をアップロードすると、Claudeがスライドを作成したり、分析を実行したり、編集案を追加したりする様子を見ることができます。完了したら、ファイルをダウンロードするか、ドライブで開くことができます。

注：これらの機能を使用するには、Claudeに外部データソースへのアクセスを許可する必要があります。プロンプトが表示されたら、「制限付きネットワークアクセスを許可」をオンに切り替えてください。

![外部データへのアクセス許可を求めるClaudeの画面。「制限付きネットワークアクセスを許可」のトグルがオンになっている](https://academy.claude.com/assets/media/f1d96f79e3a8512f7f18cacae7c299717d5a00eac8079c9494fdb12a555aeb76.png)


スキルには実行可能なコードが含まれる場合があるため、慎重に使用することが重要です。

- カスタムスキルは信頼できるソースからのみインストールしてください
- Anthropicの組み込みスキルはAnthropicがテスト・管理しています
- アップロードしたカスタムスキルは、共有するまで同僚には表示されません
- 外部ソースからカスタムスキルをインストールする場合は、使用前にその内容を確認し、何を行うスキルなのかを把握してください

Anthropicの組み込みスキルは一般的なドキュメント作成タスクをカバーしていますが、スキルの真価は独自のスキルを作成することで発揮されます。カスタムスキルを使えば、特定のワークフロー、ブランドガイドライン、作業方法をClaudeに教えることができます。そうすれば、関連するタスクの際にClaudeがその知識を自動的に適用してくれます。

カスタムスキルを作成する最も簡単な方法は、Claude自身との会話を通じて行うことです。コードを書いたり、手動でファイルを作成したりする必要はありません。Claudeが技術的な構造を処理してくれます。

会話を通じてスキルを作成する手順は以下のとおりです。

1. **新しいチャットを開始し**、作成したいものをClaudeに伝えます。たとえば、「四半期のビジネスレビューを書くためのスキルを作成したい」や「プレゼンテーションにブランドガイドラインを適用するスキルが必要」などです。
2. **Claudeの質問に答えます。** Claudeはワークフローについてインタビューし、次のようなことを尋ねます。このスキルは何をすべきですか？この種の作業で良い成果物とはどのようなものですか？このスキルを使用する場面の例を教えてもらえますか？
3. **参考資料がある場合はアップロードします。** テンプレート、スタイルガイド、ブランドアセット、または自信作の例があれば、Claudeが求めているものを正確に理解する助けになります。
4. **スキルを保存します。** 完了すると、Claudeは適切に構造化されたスキルを含むファイルを生成します。そのファイルで**スキルを保存**を使用してスキル一覧に追加すると、スキルはClaudeが使用できる状態になります。

**スキルを確認する。** 左サイドバーの「カスタマイズ」タブを見つけてください。そこで利用可能なすべてのスキルを確認でき、手動またはClaudeとのチャットを通じてスキルを編集することもできます。

作成したカスタムスキルは、Anthropicの組み込みスキルと並んでスキル一覧に表示されます。それ以降、関連するタスクに取り組む際にClaudeが自動的にスキルを呼び出します。手動でトリガーする必要はありません。反復によってスキルを改善することもできます。Claudeにスキルの編集を依頼すれば、ファイルを更新してくれます。

**自分のスキルが見当たりませんか？** Claudeが作成したファイルをダウンロードし、自分で追加してください。**カスタマイズ > スキル**で**追加**をクリックし、次に**スキルをアップロード**をクリックします。

スキルもプロジェクトもClaudeにより多くのコンテキストを与えるために使えるなら、それぞれいつ使うべきなのか疑問に思うかもしれません。次のように考えてください。**プロジェクトは知識を保存し、スキルはタスクを実行します**。

**プロジェクト**はナレッジハブです。作業を理解するためにClaudeが必要とする参照資料（プロジェクト仕様、会議メモ、調査ドキュメントなど）を保管します。プロジェクトにファイルをアップロードすると、Claudeはそのプロジェクト内のすべての会話でその情報を活用します。

**スキル**は手順マシンです。Claudeがタスクを*どのように*実行すべきか（具体的な手順、操作の順序、毎回従うべき方法論）をエンコードします。繰り返し行うワークフローをClaudeに一貫して実行させたい場合に、スキルが力を発揮します。

この2つの機能は互いを補完し合います。スキルはプロジェクトに保存された知識を参照できます。たとえば、「顧客コール準備」スキルはプロジェクトのナレッジベースにアップロードされた顧客プロファイルから情報を取得できます。プロジェクトは*何を*（情報）、スキルは*どのように*（プロセス）を提供します。

|  | プロジェクト | スキル | 
|---|---|---|
| **目的** | Claudeが参照する知識を保存 | Claudeが実行するプロセスを定義 | 
| **最適な用途** | 長期的なコンテキスト、参照資料、チームコラボレーション | 繰り返しのワークフロー、複数ステップのタスク、一貫した方法論 | 
| **例** | 顧客ハブ、リサーチバディ、フィードバック生成 | プロセスガイドライン（ブランドや法務など）、ブログ下書き、PDF作成 | 
| **持続性** | プロジェクト内のすべてのチャットで知識を利用可能 | スキルが呼び出されたときに指示が適用される | 

次に進む前に、以下について考えてみてください。

- 定期的に作成しているドキュメントで、Claudeの組み込みスキルを活用できそうなものは何ですか？
- カスタムスキルの候補になりそうな、繰り返しのワークフローはありますか？
- スキルによって、ドキュメント作成やデータ分析に対する考え方がどのように変わりそうですか？

次のレッスンでは、コネクタを使ってClaudeの活用範囲を広げていきます。これらの強力なツールにより、情報収集がシームレスになり、実際に作業しているツール内でClaudeがアクションを実行できるようになります。
