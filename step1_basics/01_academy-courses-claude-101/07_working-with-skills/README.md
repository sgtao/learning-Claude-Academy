## 概要
Claude 101 のレッスン 7「スキルを活用する」の本文です。スキルは、特定のタスクで Claude の性能を高めるために動的に読み込まれる、指示・スクリプト・リソースをまとめたフォルダだと説明されます。Anthropic スキルとカスタムスキルの 2 種類、すべてのプランで使えること、コード実行とファイル作成の有効化、会話でカスタムスキルを作る 4 つの手順、プロジェクト（知識を保存）とスキル（タスクを実行）の違い、信頼できるソースからのみ導入する注意を扱います。注意：本文に見出しは無く、1 つながりです。動画と画像は読めておらず（動画の字幕は取っていません）、リンク先のページも読んでいません。動画のキャプションの行が本文に 2 回続けて残っています。ナビ・フッターなどのページ枠の文言は見当たりません。

## 生成AIの総括
### スキルは「やり方」を預ける仕組み、プロジェクトは「知識」を預ける仕組み
- 横断分析：
  - 役割の分担：知識の保存はプロジェクト、手順の実行はスキルで、互いを補完する。
  - 入口の低さ：組み込みスキルは自動で呼び出され、カスタムスキルも会話だけで作れるため、特別な技術は要らない。
  - 条件と責任：有効化には条件（コード実行とファイル作成、Team・Enterprise の組織設定）があり、コードを含みうるため、導入する側が出所と内容を確認する。
  - 反復による改善：作って終わりではなく、Claude に編集を頼んで育てられる。
- 一言まとめ：まず組み込みスキルで体験し、繰り返す作業を 1 件、会話でスキルにして試し、信頼できるものだけを使う。
