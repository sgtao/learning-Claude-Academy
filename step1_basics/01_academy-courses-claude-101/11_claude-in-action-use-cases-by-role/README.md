## 概要
どんな仕事でもClaudeは業務の効率化を助ける、として、職種別のユースケースを紹介するレッスン。各ユースケースはユースケースギャラリーの詳細ガイドへのリンクで、手順に沿って実践できる。多くの職種に共通する3件のあと、営業・マーケティング・財務・人事・法務・研究者の順に、職種ごとに1〜3件が題名と一行説明で並ぶ。最後に、ギャラリー全体の案内と、最終モジュールでClaude CodeやClaude in Chromeなど他の使い方を紹介するという予告がある。注意：本文の大半はリンクの一覧で、各リンクに（新しいタブで開きます）という表示用の文言が付いたまま残っている。ナビ・フッターなどのページ枠の文言は残っていない。リンク先の中身は読んでいない。

## 生成AIの総括
### 自分の仕事に近い例を見つけて、手順どおりに試すための地図
- 横断分析：
  - 位置づけ：このレッスンは説明するものではなく、案内するものである。本文の大半は職種ごとの題名と一行説明のリンクで、中身（手順）はギャラリーの詳細ガイドにある。したがって、学びの本体は、自分の職種に近い例を選び、詳細ガイドで実践することにある。
  - 区分：区分は、共通・営業・マーケティング・財務・人事・法務・研究者の並びで、各区分の導入文が「Claudeを使ってできること」を1文で述べている。例は一部で、全体はギャラリーにある。
  - 書かれていないこと：本文に書かれていないこと（手順・所要の分・必要なプラン・リンク先の結果）が多い。読み手は、そこを推測で埋めず、詳細ガイドで確かめる必要がある。
  - 今後：最後のモジュールでは、Claude Code、Claude in Chromeなど、仕事が行われる場所に合わせた別の使い方が紹介される予定であり、このレッスンはその前の「何に使えるか」を見せる位置づけにある【推測】。
- 一言まとめ：まず自分の仕事に近い例を1つ選び、詳細ガイドの手順で試して、役立ち方を具体的にイメージする。
