## 生成AIの総括
### Claude には同僚に頼むように話し、返答を見ながら一緒に仕上げる
- 横断分析：
  - 役割分担：本文は繰り返し、AI の知性は Claude が、仕事を意味あるものにするコンテキストと専門知識は自分がもたらす、と述べる。プロンプトの 3 点、ファイルのアップロード、検索とツール、メモリは、いずれも「自分の側の情報を渡す手段」として読める。

- 一言まとめ：自分の仕事の文脈を、同僚に話すように Claude に渡し、返答に応じて対話を重ねる。
