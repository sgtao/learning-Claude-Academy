このコースの冒頭でお伝えしたように、Claudeは知性です。[Claude.ai（新しいタブで開きます）](https://Claude.ai)はそれを活用する一つの方法にすぎません。

Claudeは、すでに皆さんが働いている場所に合わせて設計された、いくつかの専門ツールでも利用できます。このレッスンでは、それぞれ特定のワークフローやユースケースに合わせた、Claudeを活用する追加の方法を紹介します。

Claude Code

Claude Codeは、ターミナル、IDE、ブラウザ、さらにはSlackなど、皆さんが働く場所で動作するエージェント型コーディングツールです。コードベースを理解し、コマンドを実行し、開発ワークフロー全体を自然言語で処理します。

**Claude Codeを使用すべき場面：**

- 必要なものを平易な英語で説明することで機能を構築し、Claudeにコードを書かせ、テストを実行させ、コミットを作成させたい場合
- エラーメッセージを貼り付けて、Claudeにコードベースを分析させ、問題を特定・修正させることでデバッグを行いたい場合
- 不慣れなコードベースを操作していて、さまざまな部分がどのように連携しているかについて質問したい場合
- lintエラーの修正、マージコンフリクトの解決、リリースノートの作成といった面倒なタスクを自動化したい場合
- 別のインターフェースに切り替えるのではなく、既存のIDEや開発ツールと並行してターミナルで作業することを好む場合

Claude Tag

Claude TagはClaudeを直接Slackに取り込み、チャンネルやスレッドでサポートを受けたり、SlackのコンテキストをClaudeとの会話に持ち込んだりできるようにします。スレッド内でClaudeをタグ付けするだけです。

[Claude Tag（新しいタブで開きます）](https://claude.com/product/tag)を使用すべき場面：

- Slackを離れることなく、メッセージへの返信を下書きしたり、長いスレッドを要約したり、複雑な議論を整理したりしたい場合
- Claudeにワークスペース内の関連する会話や共有ドキュメントをまとめてもらい、会議の準備をしたい場合
- 新しいチームにオンボーディングしていて、チャンネル履歴を確認することで進行中のプロジェクトを理解する手助けが欲しい場合
- バグレポートや機能に関する議論から直接コーディングタスクを引き継ぎたい場合—Claudeをタグ付けするだけで、周囲のコンテキストを使ってClaude Codeセッションを立ち上げることができます
- 会話中に業界動向、技術的な概念、会社情報について素早く答えを得たい場合

Claude Designはアイデアを実際に動作するインターフェースに変えます。欲しいものを平易な言葉で説明する—あるいはスケッチやスクリーンショットから始める—だけで、Claudeはインタラクティブなプロトタイプをアーティファクトとして構築します。これは直接編集したり、チームと共有したり、Claude Codeに渡して構築させたりできます。Claudeとのあらゆる会話の中、そしてArtifactsタブ内で動作し、claude.ai/designの専用スペースとしても利用できます。

**Claude Designを使用すべき場面：**

- 文章によるブリーフ、スケッチ、参考スクリーンショットから、コードを書かずに動作するUIプロトタイプへと進めたい場合
- デザインの方向性を探っていて、複数のバリエーションを素早く生成・比較したい場合
- マークアップを編集することなく、キャンバス上で、コメントで、あるいは依頼することで、レイアウト、コピー、インタラクションを反復したい場合（仕組みについては「アーティファクトで作成する」レッスンで扱います）
- チームのデザインシステムを使用するプロトタイプが欲しく、引き渡すものがエンジニアリングが構築するものと一致するようにしたい場合

Claude for Excel

Claude for Excelは、サイドバーを通じてClaudeを直接Microsoft Excelに取り込み、会話を通じてスプレッドシートを分析、理解、変更できるようにします。

**Claude for Excelを使用すべき場面：**

- 複雑な複数タブのワークブックを扱っていて、特定の数式や計算フローがシート間でどのように機能するかを理解したい場合
- 数式の依存関係や関係性を維持しながら、モデル全体の前提条件や入力値を更新する必要がある場合
- #REF!、#VALUE!、循環参照などのスプレッドシートエラーをデバッグしていて、Claudeにその原因を追跡させ、修正案を提案させたい場合
- 適切な数式構造を維持しながら、新しいスプレッドシートを作成したり、既存のテンプレートにデータを入力したりしたい場合
- データを可視化するためにピボットテーブルやチャートを素早く作成したい場合

Claude for PowerPointは、サイドバーとしてClaudeをMicrosoft PowerPointに取り込み、既存のテンプレートやブランドスタイルを維持したまま、会話を通じてプレゼンテーションを下書き、編集、再構成できるようにします。

**Claude for PowerPointを使用すべき場面：**

- アウトライン、ドキュメント、メモのセットを、各スライドを手作業で作成することなく、初稿のプレゼンテーションに変えたい場合
- スライドのコピーを書き直したり、引き締めたりする必要がある場合—箇条書きを短くしたり、スピーカーノートを追加したり、特定の聴衆に合わせてトーンを調整したりする場合
- 既存のプレゼンテーションを再構成していて、セクションの並べ替え、密度の高いスライドの分割、重複するスライドの統合について手助けが欲しい場合
- プレゼンテーション全体に一貫したフォーマット—タイトル、箇条書きのスタイル、レイアウト—を、各スライドを手動で修正することなく適用したい場合
- スライドについて、どのレイアウトやチャートの種類が伝えたいポイントに最も適しているかなど、素早い視覚的な提案が欲しい場合

Claude for Wordは、サイドバーとしてClaudeをMicrosoft Wordに取り込み、変更履歴やコメントを扱いながら、接続されたソースからコンテキストを取り込んで記述内容の裏付けとしつつ、開いているドキュメントを下書き、修正、再構成できるようにします。

**Claude for Wordを使用すべき場面：**

- アウトラインや大まかなメモを、チームのテンプレートに沿った構造化された初稿に変えたい場合
- セクションを修正する必要がある場合—文章を引き締めたり、特定の読者に合わせてトーンを調整したり、構造を作り直したりする場合—ドキュメントを離れることなく行いたい場合
- レビュアーのコメントや変更履歴に対応していて、その場で処理する手助けが欲しい場合
- 接続した元資料に裏付けられた下書きが欲しく、ドキュメント内の主張がその出所まで遡れるようにしたい場合

Claude for Outlookは、サイドバーとしてClaudeを受信トレイに取り込み、メールの仕分けを行い、関連するスレッドやカレンダーからのコンテキストを使って返信を下書きし、長いメールのやり取りを明確な要約や次のステップのリストに変えられるようにします。

Claude in Chrome

Claude in Chromeは、Google Chromeにサイドバーとして Claudeを追加するブラウザ拡張機能です。皆さんが取り組んでいる作業を観察し、ブラウザ内で直接アクションを実行できます。

**Claude in Chromeを使用すべき場面：**

- ブラウジング中に記事、研究論文、ウェブページを要約したい場合
- メールの返信の下書きや受信トレイの管理に手助けが必要な場合
- 繰り返しの多いフォームに入力していて、そのプロセスを自動化したい場合
- 各ステップを手動でクリックすることなく、ウェブサイトの機能をテストしたり、複数ステップのワークフローを進めたりしたい場合
- タブやタスクを移動する間もコンテキストを維持するブラウジングアシスタントが必要な場合。これは、ニッチな社内ツール、CRM、ダッシュボードからコンテキストを取り込むのに最適です。

これらのツールはそれぞれ、皆さんが実際に働いている特定の環境にClaudeの能力を拡張します。

| ツール | 最適な用途 | 動作する場所 | 
|---|---|---|
| Claude.ai | 一般的なタスク、リサーチ、ライティング、分析、ファイル作成 | ウェブ、デスクトップ、モバイルアプリ | 
| Claude Code | ソフトウェア開発、コードベースのナビゲーション、gitワークフロー | ターミナル/コマンドライン、IDE、またはブラウザ | 
| Claude Cowork | 複雑で複数ステップのタスク：リサーチブリーフ、ドキュメント作成、ファイル整理、データ分析 | デスクトップ（ProおよびMaxプランではウェブ・モバイルも利用可能、Teamプランおよび管理者が有効にしたEnterpriseプランではベータ版） | 
| Claude Tag | チームコラボレーション、会議準備、コンテキストに応じた素早い回答 | Slackワークスペース | 
| Claude Design | UIプロトタイプ、デザイン探索、デザインシステムを考慮したモックアップ | Claudeとのあらゆる会話、およびclaude.ai/design | 
| Claude for Microsoft 365 | その場での編集とドキュメント間でのコンテキストの引き継ぎ | Excel、PowerPoint、Word、Outlookのサイドバー | 
| Claude in Chrome | ウェブリサーチ、メール管理、ブラウザの自動化 | Chromeブラウザのサイドバー | 

このコースの簡単な振り返りと、LinkedInやチームと共有できる修了バッジを獲得するためのクイズで締めくくります。
