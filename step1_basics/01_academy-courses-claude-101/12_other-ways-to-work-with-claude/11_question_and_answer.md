## FAQ｜グループ1：働く場所に合わせた Claude の専門ツール
### 1. Claude.ai 以外でも Claude は使えますか
- **質問**：Claude を使う方法は、Claude.ai のほかにもありますか。
- **回答**：あります。本文は、Claude.ai は活用方法の一つにすぎず、働く場所に合わせた専門ツールでも使えると説明しています。
- **具体例**：本文の例は Claude Code、Claude Tag、Claude Design、Claude for Excel、Claude for PowerPoint、Claude for Word、Claude for Outlook、Claude in Chrome。
- **該当箇所**：本文（見出しなし）「Claudeは、すでに皆さんが働いている場所に合わせて設計された、いくつかの専門ツールでも利用できます。」

### 2. Claude Code は非エンジニアにも必要ですか
- **質問**：コードを書かない自分も、Claude Code を使うべきですか。
- **回答**：本文には、非エンジニアが使うべきかどうかは書かれていません。本文は Claude Code をコーディングツールと紹介し、場面も開発の作業を挙げています。
- **具体例**：【補足】コードを書かない人は、まず Excel・Word・Outlook・Chrome・Slack のツールの「使用すべき場面」を見る、という順番が考えられます。
- **該当箇所**：本文（見出しなし）「Claude Codeは、ターミナル、IDE、ブラウザ、さらにはSlackなど、皆さんが働く場所で動作するエージェント型コーディングツールです。」

### 3. Slack で Claude を使うにはどうしますか
- **質問**：Claude Tag は、Slack の中でどう使いますか。
- **回答**：本文によれば、スレッド内で Claude をタグ付けするだけです。チャンネルやスレッドでサポートを受けたり、Slack の内容を会話に持ち込んだりできます。
- **具体例**：本文の場面の一つは、Slack を離れずに、長いスレッドを要約すること。
- **該当箇所**：本文（見出しなし）「スレッド内でClaudeをタグ付けするだけです。」

### 4. Claude Design では何ができますか
- **質問**：Claude Design は、何のためのツールですか。
- **回答**：アイデアを、動作するインターフェース（インタラクティブなプロトタイプ）に変えるツールです。文章やスケッチ、スクリーンショットから始められます。
- **具体例**：本文の場面の一つは、文章のブリーフからコードを書かずに UI プロトタイプへ進めること。
- **該当箇所**：本文（見出しなし）「文章によるブリーフ、スケッチ、参考スクリーンショットから、コードを書かずに動作するUIプロトタイプへと進めたい場合」

### 5. Excel・PowerPoint・Word・Outlook の違いは何ですか
- **質問**：Microsoft のアプリ向けの 4 つのツールは、どう違いますか。
- **回答**：どれもサイドバーとして取り込まれますが、得意な作業が違います。Excel は表計算の分析・変更、PowerPoint はプレゼンテーションの下書き・編集・再構成、Word は文書の下書き・修正・再構成、Outlook はメールの仕分けと返信の下書きです。
- **具体例**：Excel では、#REF! などのスプレッドシートエラーの原因の追跡が、本文の場面に挙がっています。
- **該当箇所**：本文（見出しなし）「#REF!、#VALUE!、循環参照などのスプレッドシートエラーをデバッグしていて、Claudeにその原因を追跡させ、修正案を提案させたい場合」

### 6. Claude in Chrome は何をしますか
- **質問**：ブラウザの拡張機能は、何を助けてくれますか。
- **回答**：Chrome のサイドバーとして、見ている作業を観察し、ブラウザ内で直接アクションを実行します。記事の要約やフォーム入力の自動化などが場面に挙がっています。
- **具体例**：繰り返しの多いフォームへの入力を自動化する、というのが本文の場面の一つ。
- **該当箇所**：本文（見出しなし）「繰り返しの多いフォームに入力していて、そのプロセスを自動化したい場合」

### 7. Claude Cowork はどこで動きますか、条件はありますか
- **質問**：Claude Cowork の動作する場所と、使える条件を教えてください。
- **回答**：本文の表では、デスクトップで動作します。ProおよびMaxプランではウェブ・モバイルでも使え、Teamプランおよび管理者が有効にしたEnterpriseプランではベータ版とされています。ほかのツールの条件は、本文には書かれていません。
- **具体例**：自分のプランが Pro・Max・Team・Enterprise のどれかと、Enterprise の場合は管理者が有効にしているかを確かめる、という使い方が考えられます【補足】。
- **該当箇所**：本文（見出しなし）「デスクトップ（ProおよびMaxプランではウェブ・モバイルも利用可能、Teamプランおよび管理者が有効にしたEnterpriseプランではベータ版）」

### 8. どのツールを選べばよいですか
- **質問**：目的が分からないとき、どのツールから見ればよいですか。
- **回答**：本文の表は、ツールごとに「最適な用途」と「動作する場所」を並べています。自分の作業場所に当たる行から見るのが近道です【補足】。一般的なタスクなら Claude.ai が最適とされています。
- **具体例**：リサーチやライティングなど一般的な作業は、表の Claude.ai の行が当たります。
- **該当箇所**：本文（見出しなし）「一般的なタスク、リサーチ、ライティング、分析、ファイル作成」
