## FAQ｜グループ1：Claudeの特徴・得意分野・使える場所
### 1. Claude は普通のチャットボットと何が違いますか
- **質問**：Claude は、質問に答えるだけのチャットボットと同じものですか。
- **回答**：本文は、単なるチャットボットではなく、思考パートナーとなるよう設計された AI アシスタントだと説明している。単純な質問への回答にとどまらず、複雑な問題への取り組みを手助けする存在として描かれている。
- **具体例**：【補足】「来週の会議の論点が整理できていない」というとき、答えを 1 つ聞くのではなく、論点を一緒に出して並べ替えてもらう使い方が当てはまる。
- **該当箇所**：本文（見出しなし）「Claudeは単なるチャットボットではありません。あなたの思考パートナーとなるよう設計されたAIアシスタントです。」

### 2. Constitutional AI とは何ですか
- **質問**：本文に出てくる Constitutional AI とは何ですか。
- **回答**：本文では、有害または差別的な出力を避けるなどの原則に導かれて Claude が振る舞うアプローチを指す。Claude が人間の価値観に沿い、透明性を持って動作するよう訓練されていることを意味する、と説明されている。訓練の方法の詳細は、本文には書かれていない。
- **具体例**：【補足】仕事で使うとき、Claude が違法・非倫理的な活動の手助けを避けるように作られている、という背景として理解しておけばよい。
- **該当箇所**：本文（見出しなし）「このアプローチはConstitutional AIと呼ばれ、Claudeが人間の価値観に沿い、透明性を持って動作するよう訓練されていることを意味します。」

### 3. Claude に口調や性格を指示できますか
- **質問**：文章の口調や Claude の振る舞いを、こちらから指定できますか。
- **回答**：本文によれば、Claude は性格、トーン、振る舞いについて指示を受けることができる。文章作成では、構成や明瞭さを一緒に繰り返し調整できるとされる。指示の具体的な書き方は、本文には書かれていない。
- **具体例**：【補足】取引先向けのメールなら「丁寧で簡潔なトーンで」と伝え、出てきた案を見て指示を直す。
- **該当箇所**：本文（見出しなし）「Claudeは性格、トーン、振る舞いについて指示を受けることができ」

### 4. どのプランで使えて、デバイス間で続きは使えますか
- **質問**：Claude アプリはどのプランで使えますか。パソコンとスマホで続きが使えますか。
- **回答**：本文は、Free、Pro、Max、Team、Enterprise のすべてのプランタイプで利用可能と述べる。サインインしていれば、会話、プロジェクト、メモリ、設定がすべてのデバイス間で同期され、ウェブ、デスクトップ、モバイルアプリから使える。
- **具体例**：【補足】会社のパソコンで始めた会話の続きを、外出先のスマホで確認する、といった使い方が考えられる。
- **該当箇所**：本文（見出しなし）「Claudeアプリは、Free、Pro、Max、Team、Enterpriseのすべてのプランタイプで利用可能です。」
- **該当箇所**：本文（見出しなし）「サインインしていれば、会話、プロジェクト、メモリ、設定はすべてのデバイス間で同期されます。」

### 5. 長い資料を読ませることはできますか
- **質問**：ドキュメントをアップロードして、内容を理解する手助けをしてもらえますか。上限はありますか。
- **回答**：本文は、ドキュメントをアップロードすれば複雑な情報の理解を手助けしてくれるとする。大きなコンテキストウィンドウにより 20 万トークン以上（約 500 ページ以上）を取り込め、対応モデルを使う場合は Pro、Max、Team、Enterprise プランで最大 100 万トークンまで利用可能と書かれている。Free のプランでの上限は、本文には書かれていない。
- **具体例**：【補足】長い報告書をアップロードして、要点と気になる点をまとめてもらう。
- **該当箇所**：本文（見出しなし）「20万トークン以上（テキストにして約500ページ以上）を取り込むことができ、対応モデルを使用する場合はPro、Max、Team、Enterpriseプランで最大100万トークンまで利用可能です。」

### 6. Claude は何が得意ですか
- **質問**：Claude が得意とすることは何ですか。
- **回答**：本文は 5 つを挙げる。文章作成とコンテンツ制作、リサーチと分析、コーディング支援、問題解決と推論、新しいことを学ぶ。コーディングについては最大の強みの一つとされている。
- **具体例**：【補足】非エンジニアの初学者は、業務メールや報告書の下書きなど、文章作成から試すと結果を確認しやすい。
- **該当箇所**：本文（見出しなし）「Claudeは、ソーシャルメディアの投稿、業務用メール、複雑なレポートの作成であなたと協働できます。」
- **該当箇所**：本文（見出しなし）「コーディングはClaudeの最大の強みの一つです。」

### 7. Thinking とは何ですか
- **質問**：本文の Thinking という機能は何ですか。
- **回答**：Claude は、ほぼ即座に応答することも、先に時間をかけて推論することもできる。後者が Thinking と呼ばれる機能で、慎重な分析が必要な問題では、答えの前に段階を追って考えられるとされる。使い方や設定の方法は、本文には書かれていない。
- **具体例**：【補足】数字の見積りや方針の比較など、すぐに答えを出しにくい相談で意識するとよい。
- **該当箇所**：本文（見出しなし）「Claudeはほぼ即座に応答することも、先に時間をかけて推論することもできます。」
- **該当箇所**：本文（見出しなし）「問題が慎重な分析を必要とする場合、Claudeは答えを出す前に段階を追って考え抜くことができます。」

### 8. Learning mode とは何ですか
- **質問**：新しいことを学ぶときの Learning mode は何をしてくれますか。
- **回答**：本文では、答えを提供するのではなく、あなたの推論プロセスを導く新しい Claude 体験で、批判的思考力の育成を助けるとされる。有効にする方法は、本文には書かれていない。
- **具体例**：【補足】新しい業界の知識を身につけたいとき、答えを教わる代わりに、考え方を問いかけてもらう使い方が当てはまる。
- **該当箇所**：本文（見出しなし）「Learning modeは、答えを提供するのではなく、あなたの推論プロセスを導く新しいClaude体験であり、批判的思考力の育成を助けます。」

### 9. Claude.ai と Claude Code はどう違いますか
- **質問**：5 つのインターフェースのうち、Claude.ai と Claude Code の違いは何ですか。
- **回答**：Claude.ai は、ほとんどの人が Claude とやり取りする主な方法で、会話、文章作成支援、リサーチ、分析、ファイル作成に最適とされ、本コースの中心である。Claude Code は開発者向けのエージェント型コーディングツールで、ファイルの直接編集、コマンドの実行、コミットの作成ができる。
- **具体例**：【補足】非エンジニアの初学者は、まず Claude.ai を使い、Claude Code は開発を行う人向けと理解しておけばよい。
- **該当箇所**：本文（見出しなし）「Claude.aiは、会話、文章作成支援、リサーチ、分析、ファイル作成に最適です。」
- **該当箇所**：本文（見出しなし）「Claude Codeはファイルを直接編集し、コマンドを実行し、コミットを作成できます。」

### 10. Claude Tag・Claude Design・Claude for Microsoft 365 は何をしますか
- **質問**：残り 3 つのインターフェースはそれぞれ何をするものですか。
- **回答**：Claude Tag は Claude を Slack に取り込み、接続するとワークスペースのチャンネル、ダイレクトメッセージ、共有ファイルを検索して文脈を見つける。Claude Design はアイデアを実際に動作するインターフェースに変え、インタラクティブなプロトタイプを作る。Claude for Microsoft 365 は Excel、PowerPoint、Word、Outlook のサイドバーとして、開いているドキュメント内で分析、下書き作成、編集を行う。各ツールの使えるプランや権限は、本文には書かれていない。
- **具体例**：【補足】普段 Word や Excel で仕事をしている人は、Claude for Microsoft 365 が自分の仕事に近い。
- **該当箇所**：本文（見出しなし）「SlackをClaudeに接続すると、Claudeはワークスペースのチャンネル、ダイレクトメッセージ、共有ファイルを検索し、より良い応答とリサーチのために必要なコンテキストを見つけます。」
- **該当箇所**：本文（見出しなし）「欲しいものを説明するか、スケッチやスクリーンショットから始めると、Claudeがインタラクティブなプロトタイプを構築し、それを洗練させてチームに引き渡すことができます。」
- **該当箇所**：本文（見出しなし）「すでに開いているドキュメント内で分析、下書き作成、編集ができるようにし」
