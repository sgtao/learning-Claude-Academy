Claudeは単なるチャットボットではありません。あなたの思考パートナーとなるよう設計されたAIアシスタントです。このレッスンでは、Claudeが他のAIツールとどう違うのかを学び、Claudeが幅広い業務タスクにどのように役立つかを見ていきます。

- **Claudeは生活と仕事のためのAIアシスタントです**：大まかに言うと、Claudeは有害または差別的な出力を避け、人間が違法または非倫理的な活動に関与するのを助けることを避け、広く安全で有益なAIシステムとして振る舞うことを助ける原則に導かれています。このアプローチはConstitutional AIと呼ばれ、Claudeが人間の価値観に沿い、透明性を持って動作するよう訓練されていることを意味します。
- **Claudeは単なるチャットボットではありません**：Claudeは、要約、検索、創造的・協働的な文章作成、質疑応答、コーディングなど、高い信頼性と予測可能性を維持しながら、幅広い会話処理やテキスト処理のタスクをこなすことができます。Claudeを、単純な質問に答えるだけでなく、複雑な問題に取り組み、困難な状況を乗り越える手助けをしてくれる思考パートナーだと考えてください。
- **Claudeは操作しやすく、協働的であるよう設計されています**：Claudeは性格、トーン、振る舞いについて指示を受けることができ、顧客からは、Claudeが有害な出力を生み出す可能性がはるかに低く、会話がしやすく、より操作しやすいため、より少ない労力で望む出力を得られるという報告が寄せられています。
- **どこで仕事をしていてもClaudeにアクセスできます**：Claudeアプリは、Free、Pro、Max、Team、Enterpriseのすべてのプランタイプで利用可能です。サインインしていれば、会話、プロジェクト、メモリ、設定はすべてのデバイス間で同期されます。デスクにいても外出先にいても、Claudeはウェブ、デスクトップ、モバイルアプリを通じて利用できます。

Claudeは、単純な質問応答のやり取りをはるかに超えて、あなたの仕事を自動化し、かつ拡張することができる、アシスタントのようなパートナーシップを含む幅広いタスクに役立ちます。

Claudeが得意とすることをいくつか紹介します。

- **文章作成とコンテンツ制作**：Claudeは、ソーシャルメディアの投稿、業務用メール、複雑なレポートの作成であなたと協働できます。Claudeは性格やトーンについて指示を受けるよう訓練されているため、構成や明瞭さについて一緒に繰り返し調整し、あなたの声がはっきりと伝わるようにすることができます。
- **リサーチと分析**：Claudeは、リサーチの切り口を探り、調査結果をまとめ、データを分析して意味のある洞察を引き出す手助けをします。ドキュメントをアップロードすれば、Claudeが複雑な情報を理解する手助けをしてくれます。これはClaudeの大きなコンテキストウィンドウによって実現されており、20万トークン以上（テキストにして約500ページ以上）を取り込むことができ、対応モデルを使用する場合はPro、Max、Team、Enterpriseプランで最大100万トークンまで利用可能です。これにより、Claudeは1回の会話で膨大な資料を考慮に入れることができます。
- **コーディング支援**：コーディングはClaudeの最大の強みの一つです。実際の現場のコーディングタスクにおけるClaudeの高い性能により、複数のプログラミング言語にわたってコードの作成、デバッグ、説明を手助けできます。
- **問題解決と推論**：Claudeは複雑な認知タスク、数学的な問題、戦略的思考と分析、そしてリサーチを扱います。Claudeはほぼ即座に応答することも、先に時間をかけて推論することもできます。これは「Thinking」と呼ばれる機能です。問題が慎重な分析を必要とする場合、Claudeは答えを出す前に段階を追って考え抜くことができます。
- **新しいことを学ぶ**：新しいスキルを学んでいる場合でも、未知の領域を探求している場合でも、複雑な課題に取り組んでいる場合でも、Claudeはあなたの学習スタイルとペースに合わせることができます。Learning modeは、答えを提供するのではなく、あなたの推論プロセスを導く新しいClaude体験であり、批判的思考力の育成を助けます。

あなた自身の職務でClaudeを活用する方法について、[ユースケースギャラリー（新しいタブで開きます）](https://academy.claude.com/ja/all?kind=use-case)を探索してインスピレーションを得てください。AIにできること（そしてできないこと）についてさらに深く知りたい場合は、[AI Capabilities（新しいタブで開きます）](https://academy.claude.com/ja/courses/ai-capabilities-and-limitations)コースをご覧ください。

Claudeはインテリジェンスそのものであり、このコースを通じてあなたが一緒に働き方を学んでいるAIアシスタントです。その同じインテリジェンスは、それぞれ異なる種類のタスクに適した複数のインターフェースを通じて利用できます。

- **[Claude.ai（新しいタブで開きます）](https://Claude.ai)**（および関連するモバイルアプリとデスクトップアプリ）は、ほとんどの人がClaudeとやり取りする主な方法です。ここでは、質問をしたり、アイデアをブレインストーミングしたり、ドキュメントを作成・編集したりと、さまざまなことができます。Claude.aiは、会話、文章作成支援、リサーチ、分析、ファイル作成に最適です。このコースではこれを中心に扱います。
- **[Claude Code（新しいタブで開きます）](https://claude.com/product/claude-code)**は、開発者向けに設計されたエージェント型コーディングツールですが、デスクトップ上のあらゆる種類のファイル操作にも使用できます。Claude Codeはファイルを直接編集し、コマンドを実行し、コミットを作成できます。
- **[Claude Tag（新しいタブで開きます）](https://claude.com/claude-and-slack)**は、Claudeを直接Slackに取り込みます。どのチャンネルや会話からでもAIアシスタントヘッダーでClaudeとチャットしたり、スレッド内でClaudeをタグ付けしたりできます。SlackをClaudeに接続すると、Claudeはワークスペースのチャンネル、ダイレクトメッセージ、共有ファイルを検索し、より良い応答とリサーチのために必要なコンテキストを見つけます。
- **[Claude Design（新しいタブで開きます）](https://claude.ai/design)**は、アイデアを実際に動作するインターフェースに変えます。欲しいものを説明するか、スケッチやスクリーンショットから始めると、Claudeがインタラクティブなプロトタイプを構築し、それを洗練させてチームに引き渡すことができます。これはClaudeとのあらゆる会話の中で動作するほか、claude.ai/designの専用スペースとしても利用できます。
- **[Claude for Microsoft 365（新しいタブで開きます）](https://support.claude.com/en/articles/13892150-work-across-excel-powerpoint-and-word)**は、Claudeをサイドバーとして Excel、PowerPoint、Word、Outlookに取り込み、すでに開いているドキュメント内で分析、下書き作成、編集ができるようにし、あるアプリから次のアプリへとコンテキストを引き継ぐことができます。

このコースでは主に[Claude.ai（新しいタブで開きます）](https://Claude.ai)を扱いますが、開発ワークフローでのClaudeの使用についてさらに詳しく知りたい場合は、[Claude Code in Action（新しいタブで開きます）](https://academy.claude.com/ja/courses/claude-code-in-action)もご覧ください。

現在のあなたの仕事の中で、Claudeを思考パートナーとして活用することで恩恵を受けられそうなタスクは何でしょうか？カレンダーを見て、Claudeにサポートしてもらいたいタスクをいくつか特定してみてください。（カレンダーを接続すれば、これをClaudeに代わりにやってもらうこともできます。「ツールを接続する」のレッスンでコネクタの設定方法を取り上げます。）
