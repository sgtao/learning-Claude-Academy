## Claudeは「答える道具」ではなく<br>==一緒に考える相手==
lead: 原本の冒頭の主張と、その理由（Why So）
- **位置づけ**：単なるチャットボットではなく、あなたの思考パートナーとなるよう設計された AI アシスタント
- **なぜそう言えるか**：単純な質問に答えるだけでなく、複雑な問題に取り組み、困難な状況を乗り越える手助けをする存在として説明されている
- **原則**：Constitutional AI と呼ばれる原則に導かれ、有害・差別的な出力や違法・非倫理的な活動への関与を避ける
point: 「思考パートナー」は原本の言葉。【補足】実際の使い心地は自分の仕事で試して確かめる
note: 根拠は、原本の本文（見出しなし）の冒頭の文と最初の箇条書き（解説メモ 02「3. セクション別の解説」）。
note: 「実際の使い心地は自分で試す」は【補足】。解説メモ 02「4. ユースケース」の方向づけに基づく。

## 本文が挙げる==4つの特徴==
- **原則**：Constitutional AI。人間の価値観に沿い、透明性を持って動作するよう訓練されている
- **幅広いタスク**：要約、検索、文章作成、質疑応答、コーディングなど、会話処理・テキスト処理をこなす
- **操作しやすい**：性格・トーン・振る舞いについて指示できる。顧客からは、少ない労力で望む出力を得られるという報告がある
- **どこでも使える**：Free・Pro・Max・Team・Enterprise の全プランで利用でき、サインインすれば会話・プロジェクト・メモリ・設定がデバイス間で同期される
note: 根拠は、原本の本文（見出しなし）の最初の 4 つの箇条書き（解説メモ 11 FAQ の 2・3・4）。
note: 「少ない労力で望む出力を得られる」は、原本では顧客からの報告として書かれている。数値や調査の出典は原本に書かれていない。

## 得意なことは==5つ==
- **文章作成とコンテンツ制作**：SNS 投稿、業務用メール、複雑なレポートを一緒に作る
- **リサーチと分析**：ドキュメントをアップロードして、複雑な情報の理解を助けてもらう
- **コーディング支援**：最大の強みの一つ。コードの作成・デバッグ・説明
- **問題解決と推論**：ほぼ即座の応答も、時間をかけた推論（Thinking）もできる
- **新しいことを学ぶ**：学習スタイルとペースに合わせる。Learning mode は答えを渡さず推論を導く
note: 根拠は、原本の本文（見出しなし）の「Claudeが得意とすることをいくつか紹介します」以下の 5 項目（解説メモ 02「3. セクション別の解説」、11 FAQ の 6・7・8）。
note: Thinking や Learning mode の設定方法は、原本に書かれていない。

## 数字は==条件つき==で覚える
lead: 原本に書かれている数字と、書かれていないこと
- **取り込める量**：20万トークン以上（テキストにして約500ページ以上）
- **最大100万トークン**：対応モデルを使い、Pro・Max・Team・Enterprise のプランの場合
- **アプリの利用**：Free を含む全プランで利用可能
- **書かれていないこと**：所要時間（要確認: このレッスンの所要時間（分））、各ツールの利用条件、Claude の限界
point: 「全プランで使える」と「100万トークンは一部プラン」は別の話
note: 根拠は、原本の本文（見出しなし）のリサーチと分析の項と、プランに関する箇条書き（解説メモ 11 FAQ の 4・5・12）。
note: 所要時間は原本に書かれていない。学習メモなど別の資料に分数がある場合も、原本で確認できるまでは書かない。
note: 限界については、原本は別コース（AI Capabilities）に案内するだけで、中身は書かれていない。リンク先は読んでいない。

## 持ち帰る==4つの教訓==と偏りチェック
1. **一緒に考える相手として使う**：答えを聞くだけでなく、考えの整理や案出しも頼む
2. **まず 1 つの得意分野を試す**：5 つのうち、自分の仕事で頻度が高いものから
3. **数字は条件ごと覚える**：100 万トークンは、対応モデルかつ一部プランの場合
4. **書かれていないことは書かれていないと区別する**：所要時間、利用条件、限界など
point: 偏りチェック：原本は公式講座の本文で、肯定的な表現が多い。限界は別コースに委ねられている【推測】
note: 1・2 は解説メモ 02 の活用案（【補足】を含む）、3・4 は原本の事実の整理。
note: 偏りチェックの【推測】は、解説メモ 05「注意点・限界」に基づく。当否は確認していない。
note: 自己学習用の振り返りの問い：自分の仕事で、Claude を思考パートナーにして恩恵を受けそうなタスクは何か。
