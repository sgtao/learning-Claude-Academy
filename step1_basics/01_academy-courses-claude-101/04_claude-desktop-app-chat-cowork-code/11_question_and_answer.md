## FAQ｜グループ1：Chat・Cowork・Codeの3つの形の使い分け
### 1. このレッスンで身につけることは何ですか
- **質問**：このレッスンで身につけるべきスキルは何ですか。
- **回答**：作業は3つの形に分類されます。そのうえで、自分が今どの形にいるかを知ることが、身につけるスキルのすべてだとされています。
- **具体例**：【補足】ある日の仕事の中で、相談しながら考える場面と、完成まで任せたい場面を意識して分けてみる、という使い方が考えられます。
- **該当箇所**：本文（見出しなし）「作業は3つの形に分類され、自分が今どの形にいるかを知ることこそが、このレッスンで身につけるべきスキルのすべてです。」

### 2. 3つの形はそれぞれアプリのどこにありますか
- **質問**：3つの形は、現在のアプリではどこで行いますか。
- **回答**：ターンごとの作業はChat、任せる作業はCowork、ソフトウェアの構築はCodeタブで行います。3つともClaudeデスクトップアプリの中にあります。
- **具体例**：相談や下書きはChat、フォルダの整理やスケジュール実行はCowork、コードの作業はCodeタブ、という対応です。
- **該当箇所**：本文（見出しなし）「ターンごとの作業はChatで行われます。任せる作業はCoworkで実行されます。ソフトウェアの構築はCodeタブで行われます。」

### 3. 新しいClaudeエクスペリエンスではChatとCoworkは別ですか
- **質問**：新しいClaudeエクスペリエンスを使っている場合、ChatとCoworkはどうなりますか。
- **回答**：ChatとCoworkの区別はなく、どちらの種類の作業も、どの会話でも行えます。新しいエクスペリエンスの具体的な画面や条件は、本文には書かれていません。
- **具体例**：【補足】自分の画面にChatとCoworkの区別が見当たらない場合は、この説明に当てはまる可能性があります。画面で確かめてください。
- **該当箇所**：本文（見出しなし）「新しいClaudeエクスペリエンスをご利用の場合、ChatとCoworkの区別はありません。どちらの種類の作業も、どの会話でも行えます。」

### 4. どんなときにChatを使いますか
- **質問**：ターンごとにやり取りする作業（Chat）は、どんなときに向いていますか。
- **回答**：答えによって次に尋ねることが変わるとき、その過程に関わり続けたいとき、すぐに終わるときです。価値がやり取りそのものにある作業の形とされています。
- **具体例**：見慣れないダッシュボードをスクリーンショットで見せて、指標の意味を尋ね、フォローアップで気にすべきものを絞ります。
- **該当箇所**：本文（見出しなし）「これは思考のパートナーとしてのClaudeです。価値がやり取りそのものにある作業の形です。」

### 5. デスクトップアプリのChatには、ブラウザ版にない機能がありますか
- **質問**：デスクトップアプリならではのChatの機能は何ですか。
- **回答**：クイックエントリー、スクリーンショットとウィンドウ共有、音声入力、デスクトップコネクタが挙げられています。前の3つには(Mac)の注記が付いています。
- **具体例**：Optionキーをダブルタップして、作業中の画面の上にClaudeを呼び出します。
- **該当箇所**：本文（見出しなし）「入力する代わりに、問題を声に出して話します。(Mac)」

### 6. どんなときにCoworkで任せますか
- **質問**：作業を任せるのは、どんな作業のときですか。
- **回答**：通常は順番にこなす複数のステップがあるとき、出力が必要な場所に置かれた完成ファイルであるとき、複数のツールにまたがるとき、スケジュールに沿って、またはあなたが他のことをしている間に実行されるべきときです。
- **具体例**：契約書や会議の文字起こしなど50以上の文書が入ったフォルダから、関連するものを見つけて要約メモを作ってもらいます。
- **該当箇所**：本文（見出しなし）「タスクに、通常は順番にこなすいくつかのステップがある。」

### 7. 任せると、Claudeが勝手に実行してしまいませんか
- **質問**：作業を任せたら、あとはClaudeにお任せになりますか。
- **回答**：手を引くことを意味しません。Claudeは範囲や形式を確かめる質問をしたり計画を見せたりし、進行中も見守って方向づけできます。行動前に確認するよう設定されている場合、メールの送信やファイルの共有などの重要なアクションは承認を待って停止します。
- **具体例**：Claudeが示した計画と出力を自分でレビューします。
- **該当箇所**：本文（見出しなし）「Claudeが行動前に確認するよう設定されている場合、メールの送信やファイルの共有など、重要なアクションについてはあなたの承認を待って停止します。」

### 8. ChatとCoworkでは、ファイルの扱いがどう違いますか
- **質問**：ターンごとのChatと、Coworkのローカルフォルダへのアクセスの違いは何ですか。
- **回答**：Chatはアップロードしたものを読み取れますが、完成ファイルはフォルダに保存せずダウンロードとして返します。Coworkは指定したフォルダの中身を読み取り、完成した作業を同じ場所に保存し直します。
- **具体例**：整形したPDFやスプレッドシートが、デスクトップや正しいフォルダに直接届く形です。
- **該当箇所**：本文（見出しなし）「Claudeにフォルダを指定すると、そこにあるものを読み取り、完成した作業を同じ場所に保存し直します。」

### 9. スケジュールタスクは、パソコンがスリープでも動きますか
- **質問**：スケジュールタスクは、コンピュータがスリープ中でも実行されますか。
- **回答**：リモートで実行されるため、コンピュータがスリープ状態でもアプリが閉じていても実行されます。ただし、コンピュータ上のファイルを使うタスクは、Claudeがアクセスできるようデスクトップアプリを開いたままにします。
- **具体例**：毎週月曜日の朝の準備のように、同じ作業を決まった頻度で任せます。
- **該当箇所**：本文（見出しなし）「タスクがコンピュータ上のファイルを使用する場合は、Claudeがアクセスできるようデスクトップアプリを開いたままにしてください。」

### 10. Coworkはどのプランで使えますか
- **質問**：Coworkや関連機能の利用条件はありますか。
- **回答**：Coworkは、Pro、Max、Team、Enterpriseのユーザーが利用できます。コンピュータ使用はPro・Maxプランでリサーチプレビュー中です。クラウド上のCoworkはProおよびMaxプランで利用でき、Teamプランおよび管理者が有効にしたEnterpriseプランではベータ版です。
- **具体例**：【補足】自分のプランがどれかは、アカウントの画面で確かめてください。
- **該当箇所**：本文（見出しなし）「Coworkは、Pro、Max、Team、Enterpriseのユーザーが利用でき、新しい機能が定期的に追加されています。」

### 11. 開発者でなくても、Codeタブを知っておく必要はありますか
- **質問**：非エンジニアは、Claude Codeを使う必要がありますか。
- **回答**：本文は、開発者向けに作られているが、自分では一度も開かないとしても知っておく価値があると述べます。開発者でない場合は、別のタブであり、このコースでは必要ない、と覚えておくことだけが求められています。
- **具体例**：Codeタブは、Pro、Max、Team、Enterpriseプランで利用できるとされています。詳しい内容は本文のリンク先（Claude Code in Action）で扱うとされていますが、リンク先の中身は読んでいません。
- **該当箇所**：本文（見出しなし）「開発者向けに作られていますが、自分では一度も開かないとしても知っておく価値があります。」

### 12. 自分の仕事で、まず何を試せばよいですか
- **質問**：レッスンを読んだあと、自分の仕事1件で何を試せますか。
- **回答**：最も手放したいタスクを1つ選び、複数ステップか、コンピュータ上にファイルを保存して整理する必要があるか、複数のツールにまたがるかを確かめます。いずれかに当てはまるなら任せる作業なので、最初に尋ねる質問ではなく、Claudeに説明する成果を書き出します。
- **具体例**：【補足】毎週同じ形で作る報告メモなどが候補になります。
- **該当箇所**：本文（見出しなし）「最も手放したいタスクを1つ取り上げてください。」
