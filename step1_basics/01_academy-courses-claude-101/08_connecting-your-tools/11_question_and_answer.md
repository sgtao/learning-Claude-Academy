## FAQ｜グループ1：コネクタの仕組み・接続手順・使い方と安全面
### 1. コネクタを使うと何が変わりますか
- **質問**：コネクタを使うと、会話の中で何ができるようになりますか。
- **回答**：Claude が、仕事の置かれたツールにアクセスし、検索や読み取り、許可があればアクションの実行ができるようになる。コピーを貼り付ける必要が減る。
- **具体例**：本文の例では、メールスレッドを探す、議事録をまとめる、今週締め切りのタスクを聞く、など。
- **該当箇所**：本文（見出しなし）「ツールを一度接続すれば、Claudeはそのツール内を検索し、情報を読み取り、コネクタが許可している場合はあなたに代わってその中でアクションを実行できます」

### 2. MCP とは何ですか
- **質問**：コネクタの説明に出てくる MCP は何ですか。
- **回答**：Model Context Protocol の略で、Claude がさまざまなアプリケーションに接続するための統一されたインターフェース（オープンスタンダード）。本文は USB-C に例えている。
- **具体例**：本文によれば、開発者はあらゆるツール向けのコネクタを構築でき、それらは Claude と連携する。
- **該当箇所**：本文（見出しなし）「MCPはAIにとってのUSB-Cのようなものだと考えてください」

### 3. ウェブコネクタとデスクトップ拡張機能は何が違いますか
- **質問**：2 種類のコネクタの違いを教えてください。
- **回答**：ウェブコネクタはクラウドサービスにリンクする。デスクトップ拡張機能は Claude Desktop アプリ経由でローカルコンピュータ上で動き、ローカルファイルやネイティブアプリに使える。
- **具体例**：ウェブコネクタは Google Drive、Notion、Slack、Asana など。デスクトップ拡張機能は、ローカルファイルアクセス、ブラウザ制御、Figma など。
- **該当箇所**：本文（見出しなし）「コネクタには、ウェブコネクタとデスクトップ拡張機能の2種類があります」

### 4. 接続はどんな順序で行いますか
- **質問**：クラウドサービスを接続する手順を教えてください。
- **回答**：コネクタを見つける、「連携する」をクリックする、認証する、権限を付与する、接続をテストする、の順。Team・Enterprise プランでは、組織のオーナーが先にそのコネクタを組織向けに追加する。
- **具体例**：接続後は、「私の[ツール名]にアクセスできますか？」のような簡単なリクエストで試す。
- **該当箇所**：本文（見出しなし）「TeamおよびEnterpriseプランでは、組織のオーナーが先にそのコネクタを組織向けに追加する必要があります」

### 5. 使いたいツールがディレクトリに無いときはどうしますか
- **質問**：必要なツールの項目が見つからない場合はどうなりますか。
- **回答**：カスタムコネクタとして追加できる。また、ディレクトリにはアプリではなくコネクタが載るため、1 つの項目が複数のツールをカバーすることがある。
- **具体例**：Atlassian Rovo コネクタは Jira と Confluence の両方にアクセスできるので、Atlassian の名前で探す。
- **該当箇所**：本文（見出しなし）「必要なツールに専用の項目がない場合は、代わりにカスタムコネクタとして追加できます」

### 6. デスクトップ拡張機能はどう入れますか
- **質問**：デスクトップ拡張機能をインストールする手順を教えてください。
- **回答**：Claude Desktop アプリをダウンロードしてインストールし、設定 > 拡張機能で拡張機能を選んで「インストール」をクリックする。追加設定があれば従う。
- **具体例**：ローカルファイルの読み取りと整理、自動化されたウェブタスクのブラウザ制御などが本文の例。
- **該当箇所**：本文（見出しなし）「これらの拡張機能により、Claudeはローカルアプリケーション、ファイルシステム、macOSやWindowsのネイティブ機能と連携できます」

### 7. Claude は自分以外の人のデータも見られますか
- **質問**：コネクタを接続すると、ほかの人の情報まで見られますか。
- **回答**：見られない。Claude がアクセスできるのは自分自身がアクセスできるデータだけ。
- **具体例**：仕事用メールを接続しても、CEO の受信トレイにはアクセスできず、自分の受信トレイだけ。
- **該当箇所**：本文（見出しなし）「仕事用メールを接続しても、ClaudeがCEOの受信トレイにアクセスできるようになるわけではありません」

### 8. 接続をやめたいときはどうしますか
- **質問**：接続はあとから解除できますか。
- **回答**：できる。カスタマイズ > コネクタ、またはサードパーティサービスのセキュリティ設定から切断できる。権限は、各アプリケーションのメニュー内で個別にオン・オフもできる。
- **具体例**：カスタムコネクタは、信頼できるソースのものだけをインストールするよう本文は求めている。
- **該当箇所**：本文（見出しなし）「ツールの接続はいつでも解除できます」

### 9. 無料プランでも使えますか
- **質問**：プランによって使える・使えないはありますか。
- **回答**：本文には書かれていない。本文が書いている条件は、Team・Enterprise プランで組織のオーナーが先にコネクタを組織向けに追加する点だけ。
- **具体例**：【補足】自分のプランで使えるかは、ディレクトリやヘルプセンターで確かめる（本文のリンク先。中身は未確認）。
- **該当箇所**：本文（見出しなし）「TeamおよびEnterpriseプランでは、組織のオーナーが先にそのコネクタを組織向けに追加する必要があります」
